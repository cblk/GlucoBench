# GlucoBench 多夜夜间基线实验：持续性特征有信号，但未证明优于 v8.3

- **日期**：2026-08-07
- **用户初始方向**：`自主研究`；批准研究“多夜稳定的夜间基线持续升高”，检验逐夜分段和跨夜重复性是否能改进当前夜间均糖筛查
- **部署结论**：**不替换 v8.3 风险公式**。最佳新候选的 AUC 点估计略高，但增益不确定且嵌套选择性能下降
- **核心结论**：跨夜 IQR 确实携带诊断信号，选择校正置换检验 `p=0.010`；但“有信号”不等于“优于现有模型”。配对 bootstrap 和完整嵌套验证均未证明增量价值

---

## 1. 背景与本轮问题

`index.html` v8.3 使用 Hall 未治疗队列校准的单特征逻辑回归：

```text
P(未治疗糖代谢异常) = sigmoid(1.064314 × 0–6 时 pooled 夜间均糖 − 6.746364)
```

该模型解决了 v8.0/v8.1 相空间特征在已治疗与未治疗人群间方向反转的问题，但仍有一个结构性局限：所有夜间点被合并成一个均值，单夜异常、记录缺失和持续多夜升高被同等处理；只要有 6 个夜间点即可产生风险。

本轮预注册问题为：

1. 逐夜计算后取中位数，能否比全部点 pooled 均值更稳健？
2. 0–3 时与 3–6 时是否携带互补信息？
3. 跨夜 IQR 能否识别“持续基线升高 + 夜间不稳定”的人群？
4. 新特征是否与空腹胰岛素和 SSPG 存在机制性联系，而不只是区分诊断标签？
5. 使用 1、2、3、5 个完整夜晚时，风险有多稳定？

## 2. 数据与只读处理

| 项目 | 数值 |
|---|---:|
| 数据源 | `raw_data.zip` 中的 `raw_data/hall.csv` |
| 原始受试者 | 57 |
| 诊断分布 | 正常 38 / 糖尿病前期 14 / 糖尿病 5 |
| 主要二元标签 | `diagnosis >= 1`，阳性 19 / 阴性 38 |
| 采样间隔 | 约 5 分钟 |
| 有效空腹胰岛素 | 53 人 |
| 有效 SSPG | 42 人 |
| 每人完整夜晚 | 中位数 6，范围 4–9 |
| ≥3 个完整夜晚 | 57/57（100%） |

原始医疗数据未解压覆盖、未修改。验证脚本直接只读 ZIP，并将派生受试者级特征写入 `output/multinight_subject_features.csv`。

为与浏览器部署严格一致，Python 侧复刻了 `index.html` 的原始路径：

- mg/dL 除以 18.0182 转为 mmol/L；
- 4–15 分钟间隔按 JS 的 `Math.round(gap/3)` 规则线性插值；
- 大于 15 分钟的间隔插入空值断点；
- pooled 夜间均糖使用全部 0:00–6:00 有效点；
- “完整夜晚”要求 0–3 时和 3–6 时各至少 48 个插值后有效点，即每半夜至少约 2 小时覆盖。

## 3. 预注册特征与候选规则

所有候选最多 2 个特征，保持纯白盒并可直接写入客户端 JavaScript。

| 候选 | 特征 | 目的 |
|---|---|---|
| `current_pooled` | 所有 0–6 时点的 pooled 均值 | v8.3 诚实基线 |
| `robust_median` | 各完整夜均值的跨夜中位数 | 降低单夜离群影响 |
| `split_baseline` | 0–3 时中位均值 + 3–6 时中位均值 | 检验前后半夜互补性 |
| `late_plus_dawn` | 3–6 时中位均值 + 黎明增量 | 检验黎明响应 |
| `level_plus_iqr` | 完整夜均值中位数 + 跨夜 IQR | 同时描述基线水平和夜间不稳定性 |

没有重新尝试 Lyapunov、DET、ENTR 或 volume；既往外部验证已经证明这些特征会随治疗状态反转，RR 去饱和实验也已关闭。

## 4. 验证协议与预注册部署门槛

### 4.1 主要验证

- 受试者级重复 10×5 分层交叉验证；同一人的多个夜晚从不跨训练/测试折。
- 标准化和 L2 逻辑回归仅在训练折拟合。
- 候选选择使用外层训练集内的 3×5 内层 OOF；外层测试折保持不可见。
- 筛查阈值在内层 OOF 中选择：灵敏度目标 ≥0.75，在满足目标的阈值中最大化特异度。
- 指标：ROC AUC、PR-AUC、Brier、灵敏度、特异度和平衡准确率。
- 2,000 次按阳性/阴性分层的配对 bootstrap 估计新旧 AUC 差值。
- 300 次标签置换，使用四个新候选的最大 AUC 作为零假设统计量，校正“选最佳候选”的多重比较。

### 4.2 部署门槛

仅当以下五项全部满足才替换 JS 风险公式：

1. 最佳新候选相对基线 `ΔAUC >= 0.02`；
2. 配对 bootstrap 95% CI 下限 `> 0`；
3. 选择校正置换检验 `p <= 0.05`；
4. 完整嵌套候选选择器相对基线 `ΔAUC >= 0.01`；
5. 至少 90% 受试者具有 3 个完整夜晚。

## 5. 主要结果

### 5.1 候选模型

| 候选 | 10×5 平均 AUC | 汇总 OOF AUC | PR-AUC | Brier |
|---|---:|---:|---:|---:|
| `current_pooled` | 0.732 ± 0.007 | **0.730** | 0.527 | 0.199 |
| `robust_median` | 0.732 ± 0.006 | 0.731 | 0.560 | 0.193 |
| `split_baseline` | 0.719 ± 0.009 | 0.722 | 0.555 | 0.199 |
| `late_plus_dawn` | 0.692 ± 0.035 | 0.708 | 0.507 | 0.203 |
| `level_plus_iqr` | **0.744 ± 0.016** | **0.749** | **0.582** | **0.190** |

`level_plus_iqr` 是点估计最好的新候选，全量拟合白盒公式为：

```text
z = −8.005615 + 1.104056 × median_night_mean + 1.471687 × night_iqr
P = sigmoid(z)
```

但该公式只作为实验结果记录，**不部署**。

### 5.2 增量证据

| 检查 | 结果 | 解释 |
|---|---:|---|
| 最佳新候选相对诚实基线 ΔAUC | +0.019 | 小于预注册 +0.020 门槛 |
| 配对 bootstrap 95% CI | −0.062 至 +0.094 | 包含零，无法排除无增益或变差 |
| bootstrap 中 ΔAUC>0 的比例 | 70.6% | 仅为倾向，不足以部署 |
| 四候选选择校正置换检验 | p=0.010 | 证明新特征族有诊断信号，不证明优于基线 |
| 完整嵌套候选选择器 AUC | 0.720 | 低于基线 0.730 |
| 内层选择次数 | level+IQR 30 / robust median 18 / split 2 | 候选选择不稳定 |

嵌套选择器在外层测试折的平均筛查表现为灵敏度 0.742、特异度 0.621；固定基线相同协议为灵敏度 0.737、特异度 0.647。新管线没有获得更好的综合操作点。

### 5.3 v8.3 公式复现审计

从原始 ZIP 独立重算并在 57 人全量拟合后得到：

```text
拟合：z = 1.064311440 × nightMean − 6.746350154
部署：z = 1.064314000 × nightMean − 6.746364000
```

- 系数绝对差约 `2.56×10⁻⁶`；
- 截距绝对差约 `1.38×10⁻⁵`。

这证明本轮单位换算、JS 插值镜像、夜间窗口和标签与 v8.3 校准路径一致。部署公式在同一 57 人上的表观 AUC 为 0.751；该数值来自全量拟合后的固定公式，不应用来替代诚实 OOF AUC 0.730。

部署固定阈值的同队列表观剖面：

| 阈值 | 灵敏度 | 特异度 | 标记比例 |
|---|---:|---:|---:|
| 0.30 | 0.737 | 0.632 | 49.1% |
| 0.50 | 0.263 | 0.842 | 19.3% |

## 6. 逐夜稳定性

以完整记录风险为参照，按时间顺序仅保留前 k 个完整夜晚：

| 夜晚数 | n | pooled 特征 AUC | 与完整 pooled 的 Spearman ρ | 风险概率 MAE | 风险档位一致率 |
|---:|---:|---:|---:|---:|---:|
| 1 | 57 | 0.680 | 0.659 | 0.113 | 64.9% |
| 2 | 57 | 0.702 | 0.861 | 0.061 | 84.2% |
| 3 | 57 | 0.727 | 0.907 | 0.047 | 82.5% |
| 5 | 55 | 0.728 | 0.988 | 0.020 | 94.5% |

该分析产生一个重要但尚未外部验证的工程信号：**单夜风险明显不稳定，约 5 个完整夜晚后才接近完整记录**。三夜的概率误差继续下降，但少数样本跨越 0.30/0.50 档位边界，使档位一致率没有严格单调上升。

由于本轮预注册的新风险公式未通过部署门槛，且该数据质量结论仍来自同一 Hall 队列，本轮没有将“至少 3/5 夜”硬编码为浏览器门槛。

## 7. 空腹胰岛素与 SSPG 机制性验证

### 7.1 相关性

| 特征 | 空腹胰岛素 Spearman ρ | p | SSPG Spearman ρ | p |
|---|---:|---:|---:|---:|
| pooled 夜间均糖 | 0.344 | 0.012 | **0.443** | 0.005 |
| 多夜中位均糖 | 0.337 | 0.011 | 0.391 | 0.010 |
| 跨夜 IQR | 0.153 | 0.276 | −0.116 | 0.478 |

夜间血糖水平与空腹胰岛素、SSPG 的方向一致，支持“夜间基线升高与胰岛素异常有关”的机制解释；跨夜 IQR 本身不支持该机制，更多像诊断分层中的异质性信号。

### 7.2 个体预测能力

| 规则 | 空腹胰岛素 LOO R² | SSPG LOO R² |
|---|---:|---:|
| `current_pooled` | 0.006 | 0.024 |
| `robust_median` | 0.015 | 0.012 |
| `split_baseline` | **0.029** | −0.085 |
| `level_plus_iqr` | −0.005 | −0.011 |

结论：相关性存在，但交叉验证解释度极低。结果**不支持为个人预测空腹胰岛素或 SSPG 数值**，也不支持把新候选宣传为独立的“隐性胰岛素异常预测器”。这与 v8.2 对 FINS 卡片“接近均值回推器”的阴性结论一致。

## 8. 部署决策与最终 JS 逻辑

| 门槛 | 是否通过 |
|---|---|
| ΔAUC ≥0.02 | 否（+0.019） |
| bootstrap 95% CI 下限 >0 | 否（−0.062） |
| 选择校正 p≤0.05 | 是（0.010） |
| 嵌套选择器 ΔAUC≥0.01 | 否（−0.010） |
| ≥3 夜覆盖率≥90% | 是（100%） |

因此 `index.html` 保持 v8.3，不修改风险公式或 UI 阈值。最终客户端算法仍为：

```javascript
const z = 1.064314 * nightMean - 6.746364;
const screenRisk = 1 / (1 + Math.exp(-z));

// >=0.50 高风险；0.30–0.50 中风险；<0.30 低风险
```

这是一次有价值的阴性部署结论：若仅看最佳点估计，会把 `median + IQR` 写入浏览器；配对不确定性和嵌套选择证明该改动尚无可靠增益。

## 11. 局限

1. Hall 只有 57 人、19 个主要终点阳性；最佳候选 ΔAUC 的区间很宽。
2. 多夜候选与 v8.3 校准仍使用同一队列，没有独立的未治疗外部队列。
3. 完整夜晚阈值“每半夜至少 48 点”是工程预注册值，尚未在独立数据中验证。
4. 时间戳被视为受试者本地钟表时间；旅行、轮班、夏令时和睡眠时段偏移无法识别。
5. 空腹胰岛素与 SSPG 的相关检验涉及多个高度相关特征；p 值应视为机制性探索，不能替代个体预测验证。
6. 五夜稳定性仅在 Hall 长记录中成立；Colas 只有约两天记录，不能验证相同结论。

## 12. 后续建议

1. **优先获取独立未治疗、多夜、带 OGTT/SSPG 标签的队列**；没有外部数据前不再调节 Hall 系数。
2. **将“至少 5 个完整夜晚”作为待验证的数据质量假设**，在独立队列预注册检验档位一致性，而不是立即硬编码。
3. **扩大带空腹胰岛素/SSPG 的样本量**；当前最高 LOO R² 仅 0.029，不足以构建个体胰岛素预测器。
4. **加入实际睡眠/进餐时间标签**；固定钟表窗口可能被晚餐、夜班或时区偏移污染。
5. **冻结本轮候选**；下一数据集只做一次外部验证，避免继续在 Hall 上搜索导致多重尝试偏差。
