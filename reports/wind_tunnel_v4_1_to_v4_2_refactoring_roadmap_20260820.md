## 0. 强制前置：三段式拓扑寻路复盘 (Mandatory Pathfinding Recap)

> 依据 AGENTS.md 第 4.A 节，任何进入具体特征工程/重构方案之前，必须先完成盲区透视→潜空间虫洞→热力学账单三段式。以下是 2026-08-20 对话中已充分展开的推演的**压缩存档**，供本文档后续方案引用，不再重复完整论证过程。

### 👁️ 盲区透视 (Blind-Spot Diagnosis)
过去两轮风洞测试（v4.0→v4.1、本轮 12 张遗留卡片审计）共同暴露的核心盲区是**"实体化妄想"（Homomorphic Illusion）**：我们习惯性地把 Takens 重构出的相空间流形，当作一个可以用刚性几何量具（角度、距离、局部斜率、单点阈值穿越）去测量的规则物体。而真实的代谢相空间是一团被生物学噪音、多尺度延迟反馈、强稳态代偿包裹的泥潭——用刚性几何量具量它，量出的是测量噪音，不是代谢信号。这正是 12 张遗留卡片（AR1、早相延迟、角速度、Ascend/Night Friction、Volume/Recovery/λ1λ2/Lyapunov/Core Dist）系统性失效的第一性原因，而不是任何单一算子的实现错误。

### 🕳️ 潜空间虫洞 (Latent Wormhole Routing)
跨学科降维打击方向已从"几何拓扑"整体迁移至**"非平衡态热力学 + 非自治动力系统的经验建模（Empirical Dynamic Modeling）"**：
1. **热力学积分替代几何量具**：唯一在两个异构队列上拿下拓扑胜利的算子 `w_carb`（磁滞做功/碳水）计算的是**积分**（做功面积），不是局部几何特征——积分天然消化了噪音与局部形变。
2. **Stark-Takens 非自治延迟嵌入**：进餐/运动等外部扰动打破了经典 Takens 定理的"自治系统"前提，但 Stark（1999）证明了斜积（skew-product）延迟嵌入在受迫系统下依然拓扑合法——这是我们"必须主动注入扰动才能测出摩擦力"这一策略的数学地基。
3. **S-Map 非线性可预测性 (Sugihara Simplex/S-Map)**：用局部加权非线性模型 vs 线性模型的预测能力增益 $\Delta\rho(\theta)$，直接测度"系统是否退化为线性/白噪音机器"，是 AR1/Lyapunov 的潜在降维替代品。
4. **CCM (收敛交叉映射)**：在连续多模态变量（CGM vs 心率/EDA/体温）之间侦测因果支配权的方向与强度，是尚未开垦的跨域代偿测度处女地——但**不适用于离散的进餐脉冲输入**（数学奇点，见第 3 节 Phase D 风险声明）。

### 🔥 实验热力学账单 (Thermodynamic Bill for Impact)
1. **患者负担代价**：任何基于扰动的算子（`w_carb` 及未来的同类候选）都要求用户主动记录进餐时间与碳水估算——这是当前 `index_v4.html` 完全没有的交互通道，意味着必须新增一个会增加用户输入负担的 UI 模块，且该输入本身的噪音（自报碳水误差）已在 BIG IDEAs 队列观察到可能污染归一化分母（`delta_g` 反超现象，已排查为队列特有噪声，非普适缺陷，但风险未被完全排除）。
2. **样本量代价**：S-Map/CCM 等更高阶的非线性算子对数据长度和密度的要求远高于现有算子，在 n<20、周期 <7 天的队列（如 BIG IDEAs）上可能连基础的收敛性检验都做不到，必须先做最小可行性验证，不能直接扑向全队列分析。
3. **多模态代价**：CCM 的真正猎场（心率/EDA/体温 vs 血糖）要求生产 UI 具备多模态数据摄入通道，这是当前架构完全没有的巨大工程投入，在验证 CCM 本身有无信号之前不应贸然投入。
4. **既有认知资产的代价**：`relaxationTime` 已消耗三轮算法重设计与三个队列测试仍未毕业——任何新研究方向都必须接受"可能重复这一结局"的心理预期，不承诺必然成功。

## 4. 2026-08-20 15:58 架构决策裁决（用户批准，v4.2 正式启动）

> 本节记录用户对第 0 节三段式寻路提案中"进餐扰动层 / 多模态层 / 单维时间序列层"三条虫洞路由的最终裁决。裁决内容对第 3 节 Phase B/C/D 的范围与优先级构成约束性修正，具体条款如下：

### 4.1 进餐扰动层：冻结现状，正式否决 CCM

**裁决：** 离散碳水脉冲输入（进食事件）继续使用热力学积分 `w_carb`（磁滞做功/碳水），**不引入 CCM**。

**依据：** 这不是新决定，而是对第 0 节潜空间虫洞第 4 点与第 3 节 Phase D"绝对边界"已有论证的正式确认——CCM 收敛交叉映射要求两个**连续、密集采样**的动力学变量互相嵌入对方的影子流形，而进食是**离散脉冲事件**（一天 2-4 次的瞬时冲击，非连续过程变量），把 CCM 套用在"进食时刻"上没有数学意义上的影子流形可供嵌入——这是一个**数学奇点**，不是"精度不够"的工程问题，无法通过更多数据或调参解决。`w_carb` 的绝对曲线积分设计恰好是应对离散冲击的正确物理量具：它测的是"冲击发生后系统消耗了多少做功来吸收扰动"，不需要假设进食过程本身是连续可嵌入的动力学变量。**Phase B（`w_carb` 第三扰动源探索/标准 3 复议）维持第 3 节原方案不变，本裁决只是关闭了"未来该不该改用 CCM"这一支线疑问，不改变 Phase B 的执行内容。**

### 4.2 多模态层：CCM 降级为"武器库登记"，暂不试验

**裁决：** 将 CCM 正式登记为连续多模态数据（CGM vs 心率/睡眠/EDA/体温）因果支配力测度的**储备武器**，专门用于未来"自主神经 vs 胰岛素"因果方向判定这一具体科研问题，但**本轮不做任何代码实现或可行性试算**。

**依据：** 第 3 节原 Phase D 方案要求"先在 BIG IDEAs/mcPHASES 做 1-2 个受试者的收敛曲线可行性检验"——这本身没有变，但用户本次的措辞是"登记入武器库"而非"启动可行性检验"，因此范围收窄为纯文档动作。新建 `reports/multimodal_causal_weapon_registry.md` 作为独立于《候选张量算子暂存区》的登记文件（因为 CCM 尚未进入"单队列测得初步信号"阶段，写进《候选算子暂存区》的候选登记表会造成"暂存区"语义污染——那张表是给**已有初步实证**的候选算子做多队列交叉印证的缓冲层，而 CCM 目前是**零实证的储备工具**，两者治理阶段不同，必须分开存放）。

### 4.3 单维时间序列层：S-Map 正式列入 v4.2 调研计划，目标顶替 AR1/Lyapunov

**裁决：** 将 S-Map 非线性可预测性增益 $\Delta\rho(\theta)$ 正式列为 v4.2 候选张量算子，按第 3 节 Phase C 四段式流程启动，**目标是替代已被 2026-08-19 风洞审计判定为 Fail-Closed/冗余的 AR1（临界慢化）与 Lyapunov（李雅普诺夫代理）这两张几何遗留卡片**。

**依据：** AR1（lag-1 自相关）本质上假设系统是**线性**的——它测的是"线性记忆衰减速度"，对真正的非线性临界慢化（系统从混沌/非线性动力学退化为准线性/白噪音的过程）视而不见；而现有 Lyapunov 代理算法与嵌入维度 `dim` 强耦合（Stanford $\rho=-0.753$，Shanghai $\rho=-0.557$，见 `candidate_tensor_staging_matrix.md` 冗余审计），本就不是独立测度。S-Map 用"局部加权非线性模型 vs 全局线性模型（$\theta=0$ 退化态）"的预测能力增益 $\Delta\rho$ 直接测度"系统的非线性确定性结构是否还存在"——这是 AR1/Lyapunov 两者共同想测但都没测准的同一件事（系统僵硬度/临界慢化）的正规军版本。**执行顺序遵循第 3 节 Phase C 原方案的四段式，不跳步**：先完成异常靶点圈定与算法形式化（本节起正式开始），再在 Hall 做工程实现+烟雾测试，再选未测过的队列做真正的样本外分组检验，最后接受第 9.3 节《拓扑胜利判定》。
