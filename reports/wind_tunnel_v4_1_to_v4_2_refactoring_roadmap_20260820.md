## 0. 强制前置：三段式拓扑寻路复盘 (Mandatory Pathfinding Recap)

> 依据 AGENTS.md 第 4.A 节，任何进入具体特征工程/重构方案之前，必须先完成盲区透视→潜空间虫洞→热力学账单三段式。以下是 2026-08-20 对话中已充分展开的推演的**压缩存档**，供本文档后续方案引用，不再重复完整论证过程。

### 👁️ 盲区透视 (Blind-Spot Diagnosis)
过去两轮风洞测试（v4.0→v4.1、本轮 12 张遗留卡片审计）共同暴露的核心盲区是**"实体化妄想"（Homomorphic Illusion）**：我们习惯性地把 Takens 重构出的相空间流形，当作一个可以用刚性几何量具（角度、距离、局部斜率、单点阈值穿越）去测量的规则物体。而真实的代谢相空间是一团被生物学噪音、多尺度延迟反馈、强稳态代偿包裹的泥潭——用刚性几何量具量它，量出的是测量噪音，不是代谢信号。这正是 12 张遗留卡片（AR1、早相延迟、角速度、Ascend/Night Friction、Volume/Recovery/λ1λ2/Lyapunov/Core Dist）系统性失效的第一性原因，而不是任何单一算子的实现错误。

### 🕳️ 潜空间虫洞 (Latent Wormhole Routing)
跨学科降维打击方向已从"几何拓扑"整体迁移至**"非平衡态热力学 + 非自治动力系统的经验建模（Empirical Dynamic Modeling）"**：
1. **热力学积分替代几何量具**：唯一在两个异构队列上拿下拓扑胜利的算子 `w_carb`（磁滞做功/碳水）计算的是**积分**（做功面积），不是局部几何特征——积分天然消化了噪音与局部形变。
2. **Stark-Takens 非自治延迟嵌入**：进餐/运动等外部扰动打破了经典 Takens 定理的"自治系统"前提，但 Stark（1999）证明了斜积（skew-product）延迟嵌入在受迫系统下依然拓扑合法——这是我们"必须主动注入扰动才能测出摩擦力"这一策略的数学地基。
3. **S-Map 非线性可预测性 (Sugihara Simplex/S-Map)**：用局部加权非线性模型 vs 线性模型的预测能力增益 $\Delta\rho(\theta)$，直接测度"系统是否退化为线性/白噪音机器"，是 AR1/Lyapunov 的潜在降维替代品。
4. **CCM (收敛交叉映射)**：在连续多模态变量（CGM vs 心率/EDA/体温）之间侦测因果支配权的方向与强度，是尚未开垦的跨域代偿测度处女地——但**不适用于离散的进餐脉冲输入**（数学奇点，见第 3 节 Phase D 风险声明）。

### 🔥 实验热力学账单 (Thermodynamic Bill for Impact)
1. **患者负担代价**：任何基于扰动的算子（`w_carb` 及未来的同类候选）都要求用户主动记录进餐时间与碳水估算——这是当前 `index_v4.html` 完全没有的交互通道，意味着必须新增一个会增加用户输入负担的 UI 模块，且该输入本身的噪音（自报碳水误差）已在 BIG IDEAs 队列观察到可能污染归一化分母（`delta_g` 反超现象，已排查为队列特有噪声，非普适缺陷，但风险未被完全排除）。
2. **样本量代价**：S-Map/CCM 等更高阶的非线性算子对数据长度和密度的要求远高于现有算子，在 n<20、周期 <7 天的队列（如 BIG IDEAs）上可能连基础的收敛性检验都做不到，必须先做最小可行性验证，不能直接扑向全队列分析。
3. **多模态代价**：CCM 的真正猎场（心率/EDA/体温 vs 血糖）要求生产 UI 具备多模态数据摄入通道，这是当前架构完全没有的巨大工程投入，在验证 CCM 本身有无信号之前不应贸然投入。
4. **既有认知资产的代价**：`relaxationTime` 已消耗三轮算法重设计与三个队列测试仍未毕业——任何新研究方向都必须接受"可能重复这一结局"的心理预期，不承诺必然成功。

### Phase C｜S-Map 非线性可预测性算子（全新候选研究方向，需完整走四段式科研进化流程）

对应 2026-08-20 讨论中提出的 $\Delta\rho(\theta) = \rho(\theta_{\text{best}}) - \rho(\theta=0)$ 非线性可预测性增益算子，用于替代/补充 AR1、Lyapunov 这两个已被审计为 Fail-Closed/冗余的旧算子。**必须严格走 AGENTS.md 第 4.B 节四段式，不得跳步**：

1. **异常靶点圈定**：待与人类架构师共同确定——初步假说是"深度代偿失败"人群的夜间轨迹应表现出从非线性混沌退化为近线性/白噪音（$\Delta\rho \to 0$）。
2. **高维猜想**：已在理论讨论中完成初步公式化（简单形投影 Simplex Projection 确定嵌入参数，S-Map 用局部加权核 $\theta$ 扫描 $[0, 0.5, 1, 2, 3, 4, 6, 8]$，留一法交叉验证预测相关系数 $\rho(\theta)$）。
3. **风洞对撞**（**未启动，需批准**）：先在 Hall 做工程实现 + 烟雾测试（非独立样本，只验证代码可跑），再选一个从未被此算子测过的队列做真正的样本外分组检验。
4. **拓扑胜利判定**：沿用现行标准（$P>0.80$，≥2 个独立异构队列）。

**风险声明**：这是全新研究，不确定性等同于 `relaxationTime` 的三轮重设计投入，需明确心理预期——可能重复"投入大量精力仍未毕业"的结局。

### Phase D｜多模态 CCM 可行性探索（离线科研，最远期，不改动生产 UI）

- **范围限定**：仅在已有多模态数据的队列（BIG IDEAs 的 HR/EDA/体温，mcPHASES 的 Fitbit 多表）上做**离线风洞科研**（AGENTS.md 第 9 节），探索 CCM 双向映射是否能揭示"自主神经↔血糖"的因果支配权方向/强度变化。
- **绝对边界**：不适用于离散进餐脉冲（数学奇点，已在理论讨论中论证），且**不在本阶段新增生产 UI 的多模态输入通道**——多模态摄入是巨大的工程投入，必须先在离线科研中验证 CCM 本身有无信号，再决定是否值得为其新建生产基础设施。
- **前置可行性检验（必须先做，不能跳过）**：CCM 要求连续密集的库大小（Library Size）才能观察收敛性；BIG IDEAs（n=16，6.9–9.9 天）样本量与周期长度可能连基础收敛性检验都做不到。**第一步只应挑 1-2 个受试者的数据跑一次收敛曲线，肉眼判断像不像样，再决定是否值得投入全队列分析**——绝不能直接扑向全队列统计。
