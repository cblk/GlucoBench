# GlucoBench v8.1/v8.2 实验报告：管线性能优化、MRI 阈值重校准审计与 FINS 重拟合

- **日期**: 2026-07-31
- **目标**: 对 `index.html` v8.0 已部署管线的计算方式做性能优化，并审计全部 MRI 启发式评分阈值是否与现行管线输出匹配（v8.1）；用定位到的原始 53 人训练集按现行管线重拟合 FINS 预测器（v8.2）
- **结论摘要**: 性能上，RQA epsilon 标定的排序环节实测提速 34.8x（748ms→21.5ms，n=2000），全队列复算 99.4s→47.1s；交互 tick 叠加防抖与结果缓存后由秒级降为亚百毫秒级。校准审计发现**四张指标卡片的部署阈值在当前管线下从不触发**（与 v7.1 修复过的 Lyapunov 阈值同类问题），且 v8.0 注释引用的 DET/ENTR 队列数字在当前管线不可复现——已全部按现行管线在 Colas n=208 的实测分布重校准。全部数值改动经 `js_cohort.mjs` 全队列回归验证：**208 人 × 11 字段 0 差异**，筛查风险画像逐位一致。

## 1. 背景与目标

v8.0 确立了校准筛查模型（`Lyapunov + ENTR + 夜间均糖`，OOF AUC 0.670），其中 RQA 采用全分辨率点集（无降采样）。遗留两类问题：

1. **性能**：单次 `analyze()` 中 RQA 的 epsilon 标定做全量排序（O(n² log n)），且 tau 滑条无防抖——拖动滑条每次触发整条管线；胰岛素预估与夜间均值等与控件无关的结果被逐 tick 重算。
2. **校准可信度**：MRI 启发式评分的多组阈值（volume 0.5/1.0/3.0/4.0、DET <0.85/0.90、ENTR <1.5/1.8、Dimension >2.3/2.7、Recovery >0.20/0.30）标注"按 Colas 队列校准"，但从未用**现行 JS 管线**在队列上复核过。

回答三个问题：

1. 每项指标计算的热点在哪、可优化多少（以实测为准）？
2. 部署阈值是否落在现行管线的真实输出分布内？方向是否正确？
3. 优化与重校准是否改变任何指标数值（回归安全性）？

| 项 | 值 |
|---|---|

## 3. 性能优化实验

### 3.1 热点测量（n=2000，2M 距离对）

| 环节 | 优化前 | 优化后 | 加速比 |
|---|---|---|---|
| RQA 距离收集 | 37.1 ms | 37.1 ms（不变，O(n²) 固有） | 1x |
| **RQA epsilon 排序** | **748 ms**（`[...arr].sort(比较器)`，含一次全量拷贝） | **21.5 ms**（Float64Array + quickselect 单分位） | **34.8x** |
| 整段 RQA | ~785 ms | ~60 ms | 13.4x |
| 盒计数键（字符串→整数打包） | 5.5 ms/次 | 3.1 ms/次 | 1.8x |

要点：epsilon 只需 2% 分位数（`RQA_TARGET_RR`），全量排序是 O(n² log n) 的浪费；quickselect 平均 O(n) 且不产生排序拷贝。长序列（>4M 对 ≈ 2830 点）时改用等距抽样标定 epsilon，对角线扫描重算距离——**DET/ENTR 统计始终全分辨率**（v8.0"不降采样"约束只针对线统计，不针对标定样本），内存由 O(n²)（30 天数据约 830MB）降为 O(1)。

### 3.2 交互路径去重

| 改动 | 效果 |
|---|---|
| tau 滑条 180ms 防抖（显示即时更新） | 13 次 input 突发 → 突发期间 0 次管线调用 |
| `resampleData` WeakMap 缓存 | 每次 analyze 的 4 遍重采样 → 1 遍 |
| 胰岛素预估 + 夜间均糖移入 `onDataReady()` | 每文件一次（原每 tick 4 次完整吸引子指标，含 4×Lyapunov/盒计数/Jacobi） |
| points3D/nightCore3D 从既有结果派生 | 省 2 次嵌入/3 次中位数重算 |
| 协方差预居中 + 三角累加；`VOLUME_COEFF` 补 d=1,2 精确值（原 Stirling 误差 4-6%） | 微观 |

### 3.3 回归测试捕获的真实 bug：整数键碰撞

盒计数/近邻网格的字符串键改为整数打包键后，首轮回归即发现 14 人 `dim` 由 3 变 4、150 人盒计数维变化。根因：边界点 `floor((p−min)/eps) = g`（恰在最大值处），基数 g 的打包表示不单射（`[1,0,16] ≡ [1,1,0]`）。改用基数 g+1（dim≤6、g≤16 → 键 < 17⁶ ≈ 2.4×10⁷，double 无损）后恢复逐位一致。**若无全队列回归，该 bug 会静默改变 dA/维度/熵阈值结果。**

## 4. MRI 阈值校准审计（核心发现）

全部数字来自扩展版 `js_cohort.mjs` 在 208 人上的实测分布（现行管线，非 Python 缓存）。

### 4.1 四张卡片阈值从不触发（v8.1 修复）

| 指标 | 部署阈值（v8.0） | 实测范围 | 结论 |
|---|---|---|---|
| Volume | <0.5 bad / <1.0 warn / >3.0 warn / >4.0 bad | 0.076–75.6，中位 2.23 | **35.6% 人群被判 bad**（>4.0）——误报爆炸 |
| DET | <0.85 bad / <0.90 warn | 0.981–0.999 | 永不触发，卡片恒"good" |
| ENTR | <1.5 bad / <1.8 warn | 2.04–3.90 | 永不触发 |
| Dimension | >2.3 warn / >2.7 bad / <1.2 warn | 1.236–1.831 | 永不触发 |
| Recovery 高端 | >0.20 warn / >0.30 bad | 0.050–0.199（max 0.199） | 永不触发 |

**v8.0 注释引用的校准数字不可复现**：声称 DET T2DM 0.860 vs 正常 0.909、ENTR 1.73 vs 1.97；实测为 DET 0.992 vs 0.994、ENTR 2.786 vs 2.964（方向一致，量级完全不同）。这些数字疑似来自不同的 epsilon/线统计约定，与部署实现不符——再次印证 v8.0 报告第 3.3 节的教训：**校准必须建立在与部署实现一致的指标上**。Lyapunov 是唯一例外：v8.0 声称 0.161/0.120，实测 0.161/0.120，逐位吻合，阈值 0.15/0.20 保留。

### 4.2 重校准值（基于实测分布，方向沿用 v8.0 审计结论）

| 指标 | 新阈值 | 命中率（T2DM / 健康） | 依据 |
|---|---|---|---|
| Volume | log 阈值 −1/0/2/3（即 0.37/1.0/7.4/20.1） | bad-lo 8.7%（1/17）、warn-lo 31%、warn-hi 17%、bad-hi 6.7% | Python 验证参考（validate_takens_v3 mri_score），T2DM 更低（1.62 vs 2.26）方向一致 |
| DET | <0.990 bad / <0.994 warn | 29% / 15%；65% / 44% | T2DM 更低（0.993 vs 0.995） |
| ENTR | <2.6 bad / <2.9 warn | 35% / 12%；76% / 42% | T2DM 更低（2.74 vs 2.95） |
| Dimension | 双尾：<1.38 bad / <1.42 warn；>1.70 bad / >1.66 warn | bad-lo 12%/4%、bad-hi 12%/5%；warn-lo 12%/10%、warn-hi 24%/10% | p5/p95、p10/p90；无分组差异，按卡片概念"双尾异常"设为偏离典型标志 |
| Recovery | 高端 >0.170 bad / >0.145 warn（低端保持 v7.1 的 0.05/0.08） | 6% / 1%；24% / 10% | p97/p90；T2DM 0.116 vs 健康 0.110 无分离 |
| Lyapunov | 0.15/0.20 保留 | >0.15: 53% / 29%；>0.20: 29% / 13% | 实测验证通过 |

未改动：shapeRatio（1.2/1.8，v8.0 选择，队列无信号）；筛查 LR 系数与阈值（0.30/0.50/0.70）——风险画像回归逐位一致。

### 4.3 FINS 胰岛素预测器重拟合（v8.2）

原 53 人训练集已定位至 `data1/`（PLOS Biol pbio.2005143：57 人 CGM，其中 53 人有空腹胰岛素金标准；`insulin` 均值 7.75、SD 4.40——与原常量 INSULIN_MEAN/STD 完全吻合，确认为同一训练集）。

**特征重算**：`output/js_fins_features.mjs` 直接复用 index.html 现行管线代码（vm 沙箱），严格镜像 `predictInsulinBaseline` 内部逻辑（dim=4、τ∈{5,10,15,20}、`TAU_WEIGHTS_V2` 加权聚合、mg/dL→mmol/L 换算）。53 人全部取得 4 个 τ 的特征。

**重拟合**：Ridge(alpha=1) 于原始聚合特征（与原始拟合同流程）：

| 指标 | 结果 |
|---|---|
| 样本内 R² | 0.013 |
| OOF R²（5×20 重复 CV） | −0.12 |
| LOO R² / RMSE | −0.09 / 4.59 uIU/mL（标签 SD 4.44） |
| 旧常量套现行特征 | **R²=−1.39**（证实训练公式确已变更） |
| 部署公式 vs sklearn 拟合 | 最大差 0.048 uIU/mL（仅显示舍入），无钳位触发（0/1140） |

**结论：现行管线吸引子特征对空腹胰岛素无可检测的线性信号**（原 R²≈0.04 声明本身即噪声）。新常量已替换（`REF_MEDIANS` 现与现行管线尺度一致：volume 3.537、shapeRatio 2.207、avgRecovery 0.166、dimension 1.934、lyapunov 0.207；系数 lyap −1.71、shape −0.85、avgRecovery −1.05、dim +0.11、volume +0.000171）。方向审计：四个尺度可比的特征符号与旧拟合全部一致（旧拟合方向正确，仅尺度错误）；volume 符号在旧尺度上无意义。预测分布 7.24–8.49 uIU/mL（均值 7.80±0.26），卡片保留"实验性、非诊断依据"标签（R²≈0.01）。

### 4.4 FINS R² 提升实验（设计 v1，阴性结论）

针对 4.3 的零信号，设计并执行了系统搜索（`fins_r2_experiment.py`，n=53，全部 LOO + 折内选择 + 500 次置换检验）：

| 假设 | 检验 | 结果 |
|---|---|---|
| H1 聚合毁信号 | per-tau 展开（5×4τ=20 特征） | LOO R² −0.21（比聚合的 −0.14 更差，无尺度特异信号） |
| H2 特征族太窄 | 标准 CGM 族 29 列（paper 衍生表）+ 合并族 | alpha=1 时 −2.60，调 alpha 后 −0.27；置换 p=0.67（与噪声无差别） |
| H3 模型欠调 | 折内标准化 + alpha 网格 {0.03–100} 内层 LOO + log(FINS) + Huber | 各族均改善但不越过零；log/Huber 无效 |
| 对照 | 深度 2 决策树 | −0.33（过拟合，与 v3 分类实验一致） |
| 临床上限（不移植） | Age/BMI/A1C/FBG | LOO R² +0.08（p=0.15，未显著）；**FBG 单特征 +0.097（p=0.006）** |

要点：
- 单特征筛选中最强 CGM 特征为 `max_slope`（r=0.27）、`freq_low`（r=−0.27）、`percent_below.80`（r=−0.26）——单特征 LOO R² 仅 +0.017/+0.006（p≈0.03，在多检验背景下与随机一致）
- **唯一真实信号是临床指标 FBG（r=0.44，LOO R²≈0.10，p=0.006）**，不在工具输入空间内
- 结论：CGM 单模特征（吸引子或传统、线性或树）在 n=53 下无可利用信号；FINS 卡片维持均值参照是诚实上限

## 5. 回归与端到端验证

1. **全队列回归**：优化+重校准后重跑 `js_cohort.mjs`，208 人 × 11 字段（volume/shapeRatio/avgRecovery/dimension/lyapunov/det/entr/rr/nightMean/tau/dim）与优化前**逐位相等（0 差异）**；5 个风险阈值档 Sens/Spec 完全一致（0.50 档 0.765/0.623）。
2. **计时**：全队列 99.4s → 47.1s（2.1x；RQA 段 ~13x，剩余为 Lyapunov/盒计数/Jacobi 等固定开销）。
3. **浏览器实测**（真实 Chromium，静态服务器）：演示加载、CSV 上传、滑条防抖（13 次突发 → 0 次即时调用）、视角切换、递归图渲染全部正常，无控制台错误；患者 1 全部指标与 v2 缓存逐位一致（volume 5.30、lyap 0.112、det 99.6%、entr 3.33、τ=20、dA=1.70）。
4. **阈值修复可见**：患者 1 volume=5.30 在旧阈值下判 "bad 系统发散"，新 log 阈值下判 good——卡片恢复有效工作区间。
5. **语法**：`node --check` 通过。

## 7. 局限

- **MRI 阈值在单一队列上拟合与评估**：DET/ENTR 分布高度压缩（0.981–0.999 / 2.04–3.90），阈值对 epsilon 标定细节敏感；Dimension/Recovery 无 T2DM 分离，新阈值只是"偏离典型"标志，不构成判别。MRI 定位为"供参考"，主评级仍由 0.670 AUC 的校准 LR 驱动。
- **DET/ENTR 阈值仍无法对照任何外部运行**：v8.0 声称的 0.860/0.909、1.73/1.97 的来源无法追溯；本次是"按实测重校准"而非"与黄金标准对齐"。
- **FINS 重拟合结论为阴性**：现行管线特征对空腹胰岛素无线性信号（R²≈0.01 样本内、LOO 为负），预测器实质上是均值回推器；未做非线性/多尺度搜索（超出本次范围）。
- 阈值重校准仅基于 Colas；Weinstock/Hall 等外部队列验证未做。
- 性能数字为 Bun 环境实测，浏览器 V8 方向性一致但绝对值可能不同。

## 8. 进一步改进方向

1. **外部验证重校准阈值**：用 Weinstock/Hall 的 HbA1c/空腹血糖代理标签复核新 MRI 阈值命中率与方向（优先级最高）。
2. **DET 去饱和研究**：修复后 DET≈99% 压缩在 0.02 范围内；尝试 surrogate 检验（相位随机化）或 RR 目标降至 1% 以下恢复动态范围（v8.0 报告 8.2-8）。
3. **CI 固化回归断言**：把 `js_cohort.mjs` 的指标一致性/Sens/Spec 断言纳入 CI——本次整数键碰撞正是被这类回归捕获的，说明该检查有效且必要（v8.0 报告 8.4-14）。
4. **FINS 卡片处置**：实验 v1 已系统性排除 CGM 特征空间（吸引子/传统/树/多尺度均无信号，唯一真实信号是临床 FBG）。建议：移除卡片，或保留均值参照并标注"空腹血糖（若已知）是远强于 CGM 的预测因子"；若未来获得 >200 人带 OGTT/胰岛素标签的队列可重试。
5. **FINS 特征再探索（已闭合）**：夜间窗口/传统变异性指标（TIR、MAGE）在实验 v1 中已检验，无信号。
5. **滑条重绘优化**：防抖已消除大部分卡顿；长序列下递归图（scattergl 数万点）仍可考虑仅在 pointerup 后刷新。
6. **长序列 RQA 时间**：抽样标定解决内存，但对角线扫描仍 O(n²)；30 天数据约 2-3s，可考虑"最近 N 天"窗口策略并文档化其统计含义。
