## 2. 研究问题与构念校准

### 2.1 发现问题

在 CGMacros 中，寻找同时满足下列条件的非经典 CGM 标量：

1. Libre 与 Dexcom 两种传感器方向一致且个体排序可复现；
2. 与 `log1p(空腹胰岛素)` 方向一致；
3. 不使用任何临床变量参与特征生成、标准化、筛选或阈值确定；
4. 能直接由浏览器端 JavaScript 复现。

### 2.2 验证问题

在 Hall 数据集中仅纳入 `diagnosis=0` 且 SSPG 有效的 28 人，验证冻结候选对以下共同主终点的能力：

- 连续 SSPG；
- `SSPG >= 150 mg/dL`，其中阳性 9 人、阴性 19 人。

SSPG 反映胰岛素介导的葡萄糖处置/胰岛素抵抗，不等同于空腹胰岛素浓度。因此，本轮结果只能称为“诊断正常者中的隐藏胰岛素抵抗/葡萄糖处置异常”筛查证据，不能直接改称“基线胰岛素预测”。

## 4. 冻结的 Agent 工作流

### 4.1 防泄漏边界

- 正式候选生成器只可见 `subject_id`、时间戳和 CGM 血糖。
- CGMacros 空腹胰岛素仅在候选计算完成后用于排序与选择。
- Hall 的 diagnosis 仅用于过滤；SSPG、空腹胰岛素、hs-CRP、甘油三酯和 HDL 在候选与方向冻结后才解锁。
- 统计单位始终是受试者，不把窗口、夜晚、双传感器或重复预测当成独立样本。

### 4.2 自然态与低熵窗口

- 自然态代理：本地时钟 00:00–06:00；最多取最早 6 个覆盖率不低于 80% 的夜晚。
- 90 分钟窗口、15 分钟步长，窗口覆盖率不低于 80%。
- 对每个窗口计算：

  `entropy_score = MAD(glucose) + median(|Δglucose|)×5/采样分钟 + 2×jump_fraction`

  其中 `jump_fraction` 是斜率超过 0.3 mmol/L/min 的比例，用于惩罚不符合生理限幅的跳变。
- 跨全部固定机会窗口选择熵分数最低的 1%（至少 1 个），以其窗口中位数作为演化零点代理。窗口机会数固定由记录规则决定，避免直接择取全记录绝对最小值造成长度偏倚。

### 4.3 新候选目录

| 候选 | 白盒定义与目的 |
|---|---|
| `anchor_level` | 最低熵 1% 窗口中位血糖的中位数；低熵演化零点代理 |
| `anchor_entropy` | 被选窗口熵分数的中位数；零点稳定性/物理跳变惩罚 |
| `anchor_dwell` | 夜间点落在锚点 ±0.3 mmol/L 包络内的比例；安全包络驻留 |
| `anchor_drift` | 各夜最低熵锚点的 Theil–Sen 斜率；短期代偿漂移代理 |
| `anchor_rise_fraction` | 相邻夜锚点上升的比例；方向性疲劳代理 |
| `recovery_asymmetry_q75` | 自动检测白天上升事件后，恢复时间/达峰时间的第 75 百分位 |
| `next_night_carryover` | 高事件负荷日与低负荷日的次夜锚点中位数差 |

`night_mean` 是强制简单对照，而非健康定义；`recovery_debt_q75` 是历史已测基准，不冒充新候选。

### 4.4 候选选择规则

候选需同时满足：双传感器完整人数至少 36、Libre–Dexcom Spearman 至少 0.60、两传感器与空腹胰岛素同向、最小绝对相关至少 0.10、Hall 可计算人数至少 26。全候选选择用 5,000 次置换重跑选择，报告 maxT 校正 p 值。

## 5. CGMacros 发现结果

### 5.1 自动事件检测器审计

| 传感器 | 检出事件 | 记录膳食 | 事件匹配精确率 | 膳食召回率 |
|---|---:|---:|---:|---:|
| Libre | 1,526 | 1,706 | 0.528 | 0.502 |
| Dexcom | 1,680 | 1,706 | 0.465 | 0.490 |

事件检测只匹配约一半膳食，且两传感器的动力学候选方向不稳定。因此，本轮不把恢复不对称或次夜携带作为正式 Hall 候选。

### 5.2 双传感器候选审计

| 特征 | 完整 n | 传感器间 ρ | 胰岛素 ρ（Libre） | 胰岛素 ρ（Dexcom） | 合格 |
|---|---:|---:|---:|---:|---|
| `anchor_level` | 45 | 0.684 | 0.301 | 0.432 | 是 |
| `anchor_entropy` | 45 | 0.126 | 0.221 | -0.187 | 否 |
| `anchor_dwell` | 45 | 0.611 | 0.063 | -0.087 | 否 |
| `anchor_drift` | 45 | 0.497 | 0.031 | -0.174 | 否 |
| `anchor_rise_fraction` | 45 | 0.430 | -0.053 | 0.036 | 否 |
| `recovery_asymmetry_q75` | 45 | 0.293 | 0.329 | -0.162 | 否 |
| `next_night_carryover` | 45 | 0.246 | -0.049 | 0.031 | 否 |

唯一冻结候选为 `anchor_level`，候选搜索的 maxT 校正 p=0.0434。

不过，冗余审计显示 `anchor_level` 与 `night_mean` 的 Spearman 在 Libre 为 0.889、Dexcom 为 0.909。也就是说，Agent 找到的是一个可复现的低熵“水平”特征，而不是独立于夜间水平的全新动力学维度。

## 6. Hall 隐藏 SSPG 正式验证

### 6.1 二元终点：SSPG >= 150 mg/dL

| 指标 | `anchor_level` | `night_mean` | 当前 v8.4 冻结输出 |
|---|---:|---:|---:|
| AUC | 0.781 | 0.906 | 0.825 |
| 相对 `anchor_level` 的差值 | — | -0.126 | -0.044 |

- `anchor_level` AUC 95% 分层受试者 bootstrap CI：0.596–0.942（5,000 次）。
- AUC 高于随机的一侧置换 p=0.00910（10,000 次）。
- 相对 `night_mean` 的 ΔAUC=-0.126，95% CI=-0.237 至 -0.035；“候选优于基线”的一侧置换 p=0.961。
- `anchor_level` 与 `night_mean` 在 Hall 的 Spearman ρ=0.813，再次证明高度冗余。

固定分数采用逐人留一；每个训练集内选择“灵敏度至少 0.80 后特异度最大”的阈值。最终独立个体计数为：

- TP=7、FN=2、TN=13、FP=6；
- 灵敏度 7/9=0.778，Clopper–Pearson 95% CI 0.400–0.972；
- 特异度 13/19=0.684，Clopper–Pearson 95% CI 0.434–0.874。

9 个阳性中每错 1 人就改变 11.1 个百分点，因此计数和精确区间比三位小数更重要。

### 6.2 连续 SSPG

- `anchor_level` 与 SSPG：Spearman ρ=0.346，bootstrap 95% CI=-0.053 至 0.671；双侧置换 p=0.0728。
- `night_mean` 与 SSPG：Spearman ρ=0.542，bootstrap 95% CI=0.226–0.756。
- `anchor_level` 没有达到连续共同主终点的预设显著性门槛。

### 6.3 跨夜可靠性

奇偶夜 `anchor_level` Spearman ρ=0.692，95% CI=0.394–0.867，低于冻结门槛 0.70。

### 6.4 跨域“废热”方向审计

| Hall 临床维度 | Spearman ρ | 双侧置换 p |
|---|---:|---:|
| 空腹胰岛素（25/28 配对） | 0.023 | 0.911 |
| hs-CRP | 0.136 | 0.493 |
| 甘油三酯/HDL | 0.317 | 0.0952 |

三项均为预设正方向且没有显著反向，所以形式上的方向门槛通过；但没有一项达到常规显著性，不能把它解释为已证明的跨系统“废热”。

### 6.5 Hall 全候选探索性审计

若事后允许全部 7 个候选接触 Hall SSPG，最大绝对 Spearman 仍由 `anchor_level` 获得（|ρ|=0.346），但全搜索 maxT p=0.416。该结果只用于检查是否遗漏巨大信号，不用于重新选模。

## 10. 解释、局限与下一步

### 10.1 本轮学到什么

1. 低熵窗口是可计算、白盒且跨传感器有一定复现性的框架，但目前被筛出的有效量主要仍是“血糖水平”。
2. 纯熵、驻留、漂移、手性和事件恢复特征没有跨 Libre/Dexcom 保持与空腹胰岛素的一致方向。
3. 简单夜间均糖在隐藏 SSPG 上明显强于低熵锚点。均值在这里仅作为强制对照，并未被拿来定义“健康”；结果反而说明非线性候选必须证明增量价值，不能只改名。
4. 固定时钟 00:00–06:00 不能证明睡眠或空腹；6 个夜晚的漂移也不能证明纵向代偿坍塌。

### 10.2 推荐下一周期

1. **停止在 Hall SSPG 上继续选模。** 同一 28 人反复调参会把内部验证变成训练集。
2. **获取独立、带 SSPG 或钳夹终点的 CGM 队列。** 先冻结候选目录与阈值，再进行一次性确认。
3. **若继续事件动力学，先改进干预识别。** 使用有真实餐食标签的训练/验证划分，要求双传感器事件召回与方向一致性达标后，才研究恢复包络。
4. **把低熵锚点改为“残差问题”。** 未来只研究在夜间水平匹配或从 `night_mean` 残差化以后仍存在的稳定动力学信息；原始 `anchor_level` 不再作为新颖候选。
5. **单独修复前端多 ID 导入风险。** 当前静态工具若把多个 ID 串成一条轨迹，会产生跨人伪动力学；应在独立工程周期中按 ID 分组或拒绝多 ID 文件。
