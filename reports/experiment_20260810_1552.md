# GlucoBench 九维综合血糖异常残差实验：相空间特征进入拟合，但未获得可部署增益

- 日期：2026-08-10
- 候选参数：`Omega_G`（综合血糖异常残差）
- 结论级别：跨队列内部研究 + Hall 冻结外部验证；非诊断、非治疗依据
- 部署结论：**不更新 `index.html`**。九维参数空间已完整评估，但候选未通过预注册的增量价值、双传感器一致性、连续 SSPG 和短窗稳定性门槛。

## 1. 用户初始问题与批准方向

用户要求使用当前全部数据集（包括 CGMacros）共同拥有的指标，定义一个评价样本“综合血糖异常程度”的新拟合参数；随后明确要求把 `Volume`、`Lyapunov`、`DET`、`ENTR` 一并纳入拟合参数空间，并批准执行。

只读结构审计确认，六个数据源真正共有的原始输入只有：

1. 受试者 ID；
2. 时间戳；
3. CGM 血糖值。

BMI、饮食、活动、用药、空腹胰岛素、SSPG、HbA1c 和诊断标签均不共通。本实验因此严格限制候选输入为 `id + timestamp + CGM glucose`；临床字段只作为发现或验证终点，绝不进入个人分数。

## 2. Forge 框架的可检验化

本轮使用《The Homomorphic Anchor Forge v1.0》的四步结构作为假设组织工具，但不把其中的“绝对因果真理”措辞当作医学证据。

### 2.1 拓扑骨架

把综合异常拆成九个可观察残差：高糖暴露、低糖暴露、波动耗散、恢复债务、低熵夜间锚点，以及四项相空间/RQA 结构量。

### 2.2 同态损耗

不同数据集缺少共同的饮食、睡眠、活动、胰岛素治疗和设备信息。它们不能被强行拟合；治疗状态和糖尿病类型也不能作为参数输入。所有序列采用相同时间窗、单位和浏览器数值管线，减少降维时的设备与记录长度伪差。

### 2.3 残差寻的

一个候选只有在以下层面仍存在时才被视为有效残差：CGMacros Libre/Dexcom 同受试者复现、CGMacros 与 Colas 的嵌套发现、Hall 隐藏 SSPG 冻结验证，以及 24/48 小时时窗稳定性。

### 2.4 非对称锁死

预注册部署门槛要求外部增量、连续终点、传感器一致性和时间稳定性同时成立。仅有单个 AUC 点估计不构成“咬合完成”。本轮多个关键门槛失败，因此不能宣告有效锁死。

## 3. 数据与角色分配

### 3.1 固定窗口和质量门控

- 主分析窗口：每名受试者第一段 48 小时；
- 敏感性窗口：第一段 24 小时；
- 最短时间跨度：目标窗口的 75%；
- 规则网格覆盖率：至少 60%；
- 必须存在可计算的夜间低熵锚点；
- 血糖统一为 mmol/L；
- 相空间四项直接调用 `index.html` 的生产函数，不复制数值算法。

48 小时门控后的可用样本：

| 数据集/传感器 | 可用/总数 | 实验角色 |
|---|---:|---|
| CGMacros Libre | 44/45 | 发现：空腹胰岛素；双传感器复现 |
| CGMacros Dexcom | 44/45 | 发现：空腹胰岛素；双传感器复现 |
| Colas | 191/208，T2DM 阳性 16 | 发现：二分类任务 |
| Hall | 57/57 | 完全冻结验证；正常诊断且 SSPG 完整 28 人，`SSPG>=150` 9 人 |
| Iglu | 5/5 | T1D 压力测试，不参与拟合 |
| Dubosson | 7/9 | T1D 压力测试，不参与拟合 |
| Weinstock | 184/200 | T1D 压力测试，不参与拟合 |

CGMacros 的 Libre 和 Dexcom 特征先分别计算，发现模型中再按受试者取双传感器平均，避免把同一人重复当成两个独立样本。

## 4. 九维候选特征

令规则化后的血糖为 `g_t`，单位 mmol/L。

### 4.1 五项暴露/动力学特征

1. **高糖暴露残差 `H`**

   `mean(max(g-7.8, 0) + 2*max(g-10.0, 0))`

   7.8 mmol/L 是早期分析肩点，不解释为 CGM 诊断阈值；10.0 mmol/L 对应标准 TIR 上界并追加惩罚。

2. **低糖暴露残差 `L`**

   `mean(max(3.9-g, 0) + 2*max(3.0-g, 0))`

3. **波动耗散 `V`**

   把相邻变化统一为每 5 分钟变化，扣除 `0.15 mmol/L/5min` 工程噪声底后取平均正残差。

4. **恢复债务 `R`**

   检测日间上升事件，在峰后 180 分钟内计算超过“基线 + 峰幅 25%”的归一化面积，按受试者取第 75 百分位；无事件且覆盖合格时记为 0。

5. **低熵夜间锚点 `B`**

   在 00:00–06:00 的 90 分钟滑窗中，以 `MAD + 中位绝对5分钟变化 + 跳变惩罚` 排序，提取最低熵 1% 窗口的锚点水平。

### 4.2 四项相空间特征

- `Volume`：99% 方差有效维度下的广义超椭球体积；拟合前使用 `log1p`；
- `Lyapunov`：Rosenstein-lite 一步近邻发散代理；
- `DET`：目标 RR=2%、Theiler 排除后的递归确定性率；
- `ENTR`：递归对角线长度分布的 Shannon 熵。

四项全部来自现行 `index.html` 的 `resampleData → recommendTau → estimateEmbeddingDimension → takensEmbedding → computeAttractorMetrics/computeRQA` 链路。

### 4.3 数值变换

`H/L/V/R/Volume` 使用 `log1p(max(x,0))`，其余使用原值。中心和尺度只在训练折内用稳健位置与 IQR 尺度估计；这些常数只作数值预处理，不定义生理健康。

## 5. 拟合模型与无泄漏协议

三个预注册模型族：

| 模型族 | 特征 |
|---|---|
| `base5` | H、L、V、R、B |
| `phase4` | Volume、Lyapunov、DET、ENTR |
| `full9` | 全部九项 |

共享参数写作：

`Omega_G = sum_j w_j * (transform(x_j) - center_j) / scale_j`

- 五项基础负荷系数约束为非负；
- 四项相空间系数允许正负，以容纳治疗状态方向异质性；
- CGMacros 使用 `log1p(空腹胰岛素)` 标准化回归损失；
- Colas 使用 T2DM logistic 损失；
- 两个任务各自按样本平均后等权相加；
- 使用 Elastic Net 平滑稀疏惩罚；
- 正则强度网格：`0, 0.003, 0.01, 0.03, 0.1, 0.3`；
- 外层为 5 次重复 5 折、内层 3 折；所有划分按受试者；
- 模型族按 CGMacros Spearman 与 Colas AUC 的等权复合 OOF 指标选择；若距离最佳值不超过 0.01，则选择特征更少者；
- Hall 的 SSPG、诊断和特征表现直到模型族与拟合规则冻结后才解封。

## 6. 发现阶段结果

| 模型族 | CGMacros OOF Spearman | Colas OOF AUC | Colas OOF PR-AUC | 复合 OOF |
|---|---:|---:|---:|---:|
| `base5` | **0.373** | **0.638** | **0.137** | **0.662** |
| `phase4` | 0.208 | 0.363 | 0.068 | 0.483 |
| `full9` | 0.291 | 0.557 | 0.114 | 0.601 |

`base5` 明确优于 `full9`，并非因为复杂度平局才被选择。相空间四项作为整体在 Colas 中方向低于随机，完整九维模型也降低了 OOF 泛化表现。

### 6.1 冻结全量拟合中的相空间系数

完整九维模型最终正则强度为 0.3，其四个相空间标准化系数为：

| 特征 | 系数 |
|---|---:|
| Volume | 0.000193 |
| Lyapunov | -0.000022 |
| DET | 0.000034 |
| ENTR | 0.000070 |

这些系数均被压到接近零；`full9` 的冻结 Hall AUC 与 `base5` 相同，表明其输出事实上退化为基础模型，而不是形成新的相空间增量。

### 6.2 相空间单独模型

`phase4` 冻结后几乎只保留 Volume（标准化系数 0.1167），其结果为：

- CGMacros 发现样本内空腹胰岛素 Spearman：0.262；
- Colas 样本内 AUC：0.441；
- Hall `SSPG>=150` 描述性 AUC：0.690；
- CGMacros 双传感器 Spearman：0.879，ICC：0.711。

这说明 Volume 的设备复现性较好，但复现性不等于疾病判别力。

## 7. 最终实验参数

选择后的 `base5` 被正则化为近似单一夜间锚点参数：

```text
Omega_G =
  0.00351316 * (log1p(L) - 0.00034930) / 0.01157053
+ 0.00003904 * (log1p(R) - 4.31324543) / 0.46449956
+ 0.17412961 * (B - 5.27244675) / 0.86327890
```

高糖暴露 `H` 和波动耗散 `V` 的最终系数为 0。恢复债务的系数也近乎为 0，因此实质主要由夜间锚点决定。`Omega_G` 是无量纲排序坐标，不是患病概率。输出表中的 0–100 值仅为单调显示映射；50 是 Colas 发现分布的数值中心，不是健康阈值。

## 8. Hall 冻结外部验证

### 8.1 隐藏 SSPG 二分类

诊断正常且 SSPG 完整者 `n=28`，其中 `SSPG>=150 mg/dL` 为 9 人。

| 指标 | 结果 |
|---|---:|
| `Omega_G` AUC | **0.784** |
| AUC bootstrap 95% CI | 0.583–0.938 |
| AUC 单侧置换 p | 0.0070 |
| PR-AUC | 0.662 |
| 夜间均糖 AUC | 0.766 |
| AUC 增量 | **+0.018** |
| 增量 bootstrap 95% CI | -0.139–0.182 |

候选能够进行排序，但没有达到预注册的 `+0.05` 增量，也没有证明增量大于 0。

### 8.2 连续 SSPG

- `Omega_G` vs SSPG Spearman：0.218；
- bootstrap 95% CI：-0.159–0.551；
- 双侧置换 p：0.263；
- 夜间均糖 vs SSPG Spearman：0.215。

连续共同终点未通过。二分类 AUC 的信号主要来自排序某个阈值两侧，不能解释为连续胰岛素抵抗程度。

### 8.3 Hall 诊断标签

- `Omega_G` AUC：0.679（95% CI 0.533–0.815）；
- 夜间均糖 AUC：0.713；
- 增量：-0.035（95% CI -0.162–0.088）；
- PR-AUC：0.487。

在完整未治疗 Hall 队列中，候选不如夜间均糖。

### 8.4 探索性阈值迁移

在 Colas 全量发现拟合上，以灵敏度至少 0.80 选择阈值 `Omega_G=-0.0561`：

| 队列 | 灵敏度 | 特异度 |
|---|---:|---:|
| Colas | 0.813 | 0.411 |
| Hall 诊断 | 0.895 | 0.395 |

该阈值来自全量发现拟合，只是迁移压力测试，不是独立校准操作点。低特异度进一步阻止部署。

## 9. 双传感器和记录长度稳定性

### 9.1 CGMacros Libre/Dexcom

`n=44` 对双传感器：

- `Omega_G` Spearman：0.617；
- 绝对一致 ICC：0.333；
- 分数绝对差中位数：0.440。

单特征跨传感器 Spearman：高糖暴露 0.938、Volume 0.879、夜间锚点 0.611、波动耗散 0.560、Lyapunov 0.437、ENTR 0.428、低糖暴露 0.456、DET 0.355、恢复债务 0.331。

最终分数没有达到预注册的 Spearman/ICC 0.70 门槛。主要原因是模型几乎完全依赖夜间锚点，而锚点存在明显 Libre/Dexcom 水平偏移。

### 9.2 24 小时 vs 48 小时

| 数据源 | 配对 n | Spearman | 绝对一致 ICC |
|---|---:|---:|---:|
| CGMacros Libre | 44 | 0.937 | 0.921 |
| CGMacros Dexcom | 44 | 0.816 | 0.823 |
| Colas | 191 | 0.623 | 0.679 |
| Hall | 50 | 0.490 | 0.474 |
| Weinstock | 161 | 0.689 | 0.715 |
| Iglu | 5 | 0.700 | 0.715 |
| Dubosson | 7 | 1.000 | 0.899 |

CGMacros 内部较稳定，但 Colas 与 Hall 未达到 0.70；Iglu/Dubosson 样本量极小，不能抵消主要队列的失败。

## 10. 相空间方向异质性

| 特征 | CGMacros-胰岛素 Spearman | Colas T2DM 有向关联 | Hall 正常组 SSPG Spearman |
|---|---:|---:|---:|
| Volume | +0.262 | -0.119 | +0.241 |
| Lyapunov | -0.207 | +0.339 | +0.029 |
| DET | +0.423 | -0.315 | +0.256 |
| ENTR | +0.368 | -0.364 | +0.222 |

四项均至少在一个发现任务中反向。特别是 DET/ENTR 在 CGMacros 和 Hall 呈正方向，在已治疗 Colas 中明显反向，复现了历史报告中的治疗状态异质性。由于治疗状态不是所有数据集的共同输入，无法安全地在通用分数中用条件分支修复。

## 11. 部署门槛

| 门槛 | 结果 |
|---|---|
| CGMacros 双传感器 Spearman >=0.70 | **失败：0.617** |
| CGMacros 双传感器 ICC >=0.70 | **失败：0.333** |
| Hall SSPG AUC >=0.75 | 通过：0.784 |
| Hall AUC CI 下限 >0.50 | 通过：0.583 |
| 相对夜间均糖 AUC 增量 >=0.05 | **失败：0.018** |
| 增量 CI 下限 >0 | **失败：-0.139** |
| 连续 SSPG 正相关且 p<=0.05 | **失败：rho=0.218，p=0.263** |
| 主要数据源 24/48h Spearman 均 >=0.70 | **失败：Colas 0.623，Hall 0.490** |

最终：`deployment_eligible = false`。

## 12. HTML/JavaScript 决策

`index.html` 未修改。新参数没有通过“在写前端代码前必须证明有效”的检查点，因此没有把实验性公式加入个人结果卡、顶部风险或审计日志。

当前浏览器逻辑继续保持 v8.4：治疗状态明确且三项动力学证据可用时使用既有动力学共识；治疗未知或动力学不可用时回退夜间均糖。`Omega_G` 的精确候选公式保存在结果 JSON 中，供未来独立复验，但不是当前 JS 部署算法。

## 13. 解释与局限

1. Colas 质量门控后只有 16 名阳性，外层折的 AUC 方差较大。
2. CGMacros 空腹胰岛素、Hall SSPG 和糖尿病诊断是相关但不同的生理终点；共享参数可能被迫折衷。
3. 不同 CGM 设备存在系统水平偏移，夜间锚点对这种偏移尤其敏感。
4. 48 小时已经是所有队列可共同支持的较长窗口，但远短于稳定长期 CGM 指标常用的 10–14 天；24/48 小时结果不能证明长期重测可靠性。
5. T1D 队列没有队列内非糖尿病对照，只能用于可计算性和稳定性压力测试，不能参与疾病判别拟合。
6. `SSPG>=150` 仅 9 个阳性，AUC 区间仍宽。
7. 0–100 显示映射不能解释为健康百分比、病情严重度百分比或个体患病概率。

## 14. 结论

九维“综合血糖异常”搜索给出了一个有价值的阴性结果：

- Volume、Lyapunov、DET、ENTR 已被完整纳入参数空间，而不是事先排除；
- 四项相空间特征在跨任务方向上不一致，完整九维模型的 OOF 表现低于基础五项；
- 正则化把它们的系数压到接近零；
- 最终候选退化为以低熵夜间锚点为主的分数；
- 该分数在 Hall `SSPG>=150` 上有排序信号，但没有超过夜间均糖，连续关联、设备一致性和短窗稳定性均不足。

因此，目前不能定义一个经验证的、可跨六数据集部署的“综合血糖异常程度”参数。可保留的研究假设是：**连续暴露类指标的设备复现性优于恢复/RQA 指标，但若目标是隐性胰岛素异常，夜间水平仍主导信号；下一步应首先解决设备校准和更长重复记录，而不是继续扩大相空间特征搜索。**
