## 2. v8.4 白盒算法

### 2.1 训练参考与方向证据

每项动力学指标使用对应治疗层健康对照的中位数和稳健尺度：

```text
robust_z_j = clip((x_j − median_j) / scale_j, −3, 3)
evidence_j = clip(direction_j × robust_z_j, 0, 3)
DynamicScore = median(evidence_Lyapunov, evidence_DET, evidence_ENTR)
```

三项中位数要求至少两个指标共同支持异常；单项异常不能改变风险。

### 2.2 未治疗路径

异常方向：Lyapunov 低、DET 高、ENTR 高。

| 指标 | 健康中位数 | 稳健尺度 | 方向 |
|---|---:|---:|---:|
| Lyapunov | 0.217473287 | 0.057793059 | −1 |
| DET | 0.985284779 | 0.004363252 | +1 |
| ENTR | 2.627792330 | 0.171617411 | +1 |

```text
logit(P) = −6.350735525
         + 0.854053726 × nightMean
         + 1.165467261 × DynamicScore
```

筛查阳性阈值为 0.255436；对应严格内部外层估计灵敏度 0.775、特异度 0.597。概率 ≥0.50 显示为高风险。

### 2.3 已治疗路径

异常方向：Lyapunov 高、DET 低、ENTR 低。

| 指标 | 健康中位数 | 稳健尺度 | 方向 |
|---|---:|---:|---:|
| Lyapunov | 0.112024365 | 0.068787790 | +1 |
| DET | 0.994703680 | 0.003070961 | −1 |
| ENTR | 2.954050319 | 0.308323224 | −1 |

```text
logit(P) = −4.869635504
         + 0.373950025 × nightMean
         + 0.660310825 × DynamicScore
```

筛查阳性阈值为 0.064470；对应严格内部外层估计灵敏度 0.798、特异度 0.467。概率 ≥0.50 显示为高风险。

### 2.4 未知和不可计算回退

治疗状态默认值为“未知”。治疗未知或 Lyapunov/DET/ENTR 任一不可计算时，动力学共识不能改变概率，严格回退 v8.3：

```text
P = sigmoid(1.064314 × nightMean − 6.746364)
```

测试中该回退与 v8.3 的最大绝对差为 0。

## 4. 实现验证

### 4.1 Python 与浏览器逐人一致性

`export_v84_expected.py` 使用原验证模块重新拟合全量 Hall/Colas 分层模型，输出独立 Python 期望概率。`validate_v84_deployment.mjs` 直接从 `index.html` 加载浏览器函数并逐人比较：

- Hall 57/57 通过；
- Colas 208/208 通过；
- 参数、健康参考和逐人概率误差均小于 `1e-12`；
- 治疗未知回退最大差为 0；
- 动力学缺失回退最大差为 0；
- 单项异常不改变中位数共识风险；任意两项同向异常均提高风险。

全量拟合 AUC 仅作实现诊断，不作为验证指标：Hall 0.809、Colas 0.692。正式证据仍使用上一轮 20×5 OOF 的 0.778 和 0.642。

### 4.2 语法与结构

- `index.html` 内联 JavaScript 通过 VM 语法检查；
- Python 验证/导出脚本通过 `py_compile`；
- Node 部署验证脚本通过 `--check` 和运行时断言；
- 原始医疗数据没有修改；所有期望值和检查结果写入 `output/`。
