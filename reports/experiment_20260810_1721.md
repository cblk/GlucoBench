# 五维有界血糖异常模型：跨队列与稳定性约束探索

- 日期：2026-08-10
- 主候选：`stability_base5`
- 输入：`hyper_burden`、`hypo_burden`、`variation_load`、`recovery_debt`、`anchor_level`
- 临床靶标：`CCAS-core`；Hall `CCAS-full`、OGTT/SSPG 隐性异常和 HOMA-IR 为次要探索终点
- 结论级别：三队列 leave-one-cohort-out 内部研究；Hall 已在上一轮揭盲，不再属于独立外部验证
- 最终结论：**未达到候选冻结门槛，不修改 `index.html`**

## 1. 用户问题与批准方向

上一轮九维模型失败，但五维消融在 Hall 中出现较强点估计。用户要求进一步探索五维模型，并批准以下方向：

1. 用有界 sigmoid 白盒模型替代可能超过 100 的线性坐标；
2. 检查五维组合是否真正优于 `nightMean` 和单一 `anchor_level`；
3. 使用 CGMacros 双传感器和所有队列的 24/48 小时配对加入稳定性约束；
4. 把 Hall 作为已揭盲探索队列，采用三队列留一验证，不再宣称独立外部验证；
5. 即使结果较好，也只冻结等待新队列复验的候选，不直接部署。

本轮原始数据、压缩包和 `index.html` 均只读。

## 2. 临床靶标与数据角色

主靶标沿用上一轮预先定义的连续异常分数：

```text
q(x; P, D) = sigmoid(4 * (x-P)/(D-P))
CCAS-core = 100 * [0.6*max(q_A1C,q_FPG) + 0.4*mean(q_A1C,q_FPG)]
```

该分数让接近异常阈值、但尚未越界的样本得到渐进权重，而不是被硬编码为 0。它是实验验证靶标，不是临床诊断量表。

| 队列 | 主分析 n | 标签角色 |
|---|---:|---|
| CGMacros | 44 | A1C+FPG `CCAS-core`；Libre/Dexcom 一致性 |
| Colas | 191 | HbA1c+glycaemia `CCAS-core` |
| Hall | 55 | A1C+FPG `CCAS-core`；已揭盲探索队列 |
| Iglu | 5 对 | 无临床标签；仅24/48小时稳定性 |
| Dubosson | 7 对 | 无临床标签；仅24/48小时稳定性 |
| Weinstock | 161 对 | 无临床标签；仅24/48小时稳定性 |

CGMacros 有 44 对 Libre/Dexcom 24小时数据、44 对48小时数据；Colas 有191对24/48小时数据，Hall有50对。

## 3. 五维模型

主模型为：

```text
S5 = 100 * sigmoid(
  beta0
  + betaH*z(log1p(hyper_burden))
  + betaL*z(log1p(hypo_burden))
  + betaV*z(log1p(variation_load))
  + betaR*z(log1p(recovery_debt))
  + betaB*z(anchor_level)
)
```

所有系数约束为非负。这样既保持白盒可解释性，也保证输出严格位于 0–100；但 0–100 只表示模型拟合坐标，不是概率或临床风险百分比。

监督部分使用软标签 logistic cross-entropy，各临床队列等权。稳定性损失为同一受试者两次测量预测差的均方：

```text
total loss = equal-cohort clinical loss
           + gamma * equal-pair-group stability loss
           + elastic-net penalty
```

正则强度网格为 `0, 0.001, 0.003, 0.01, 0.03`，稳定性权重为 `0, 0.1, 0.3, 1, 3`，均只在内层3折中选择。

## 4. 对照模型与验证协议

冻结五个模型族：

| 模型 | 输入 | 稳定性惩罚 |
|---|---|---|
| `night_mean` | 夜间均糖 | 无 |
| `anchor_only` | 低熵夜间锚点 | 无 |
| `base5_no_anchor` | 前四维 | 无 |
| `bounded_base5` | 全五维 | 无 |
| `stability_base5` | 全五维 | 内层选择 |

外层严格按队列留出：

1. CGMacros+Colas 训练，Hall 测试；
2. CGMacros+Hall 训练，Colas 测试；
3. Colas+Hall 训练，CGMacros 测试。

被留出临床队列的标签和稳定性配对均不进入该折训练。无标签的 Iglu、Dubosson、Weinstock只贡献稳定性配对。

## 5. 三队列 LOCO 主结果

| 模型 | CGMacros rho | Colas rho | Hall rho | 宏平均 rho | 宏平均 RMSE |
|---|---:|---:|---:|---:|---:|
| `night_mean` | 0.839 | 0.105 | 0.354 | 0.433 | 36.49 |
| `anchor_only` | 0.750 | 0.155 | 0.379 | 0.428 | 36.87 |
| `base5_no_anchor` | 0.907 | 0.091 | 0.466 | 0.488 | 32.77 |
| `bounded_base5` | **0.907** | **0.188** | 0.528 | **0.541** | 32.95 |
| `stability_base5` | 0.907 | 0.150 | **0.547** | 0.535 | **32.66** |

`stability_base5` 相对基线：

- 宏平均 rho 相对 `night_mean` 增加 **0.101**，配对 bootstrap 95% CI 0.024–0.187；
- 相对 `anchor_only` 增加 **0.106**，95% CI 0.023–0.196；
- 宏平均 rho 95% CI 为 0.437–0.613。

这些结果证明五维组合包含超出夜间水平的排序信息，但宏平均掩盖了明显异质性：Colas rho 只有 **0.150**（95% CI 0.015–0.281），低于冻结门槛0.20，且 R²=-1.897。模型仍不能在三个临床队列间稳定迁移。

无稳定性惩罚的 `bounded_base5` 宏平均 rho 反而略高0.0066。两者差异很小，不能证明稳定性损失改善临床泛化。

## 6. 稳定性权重的不稳定性

三个外层训练任务都选择 `gamma=1`：

| 留出队列 | lambda | gamma |
|---|---:|---:|
| CGMacros | 0.03 | 1 |
| Colas | 0.003 | 1 |
| Hall | 0 | 1 |

但在三个临床队列全部参与、为描述性最终公式重新进行内层选择时，最优组合变成 `lambda=0, gamma=0`。这意味着稳定性正则是否必要并不稳定，不能把它锁死为可靠模型组成部分。

## 8. 特征贡献与重采样稳定性

平均绝对 logit 贡献占比：

| 特征 | 贡献占比 | bootstrap 正系数频率 |
|---|---:|---:|
| hyper_burden | **74.5%** | 100.0% |
| hypo_burden | 0% | 4.4% |
| variation_load | 0% | 0% |
| recovery_debt | 10.5% | 78.8% |
| anchor_level | 15.0% | 88.0% |

`hyper_burden` 超过预设70%主导上限；`recovery_debt` 的正系数频率略低于80%门槛。名义上的五维模型实质退化为“高糖负荷+夜间锚点+弱恢复项”三维模型。

逐特征删除的宏平均 rho：

| 删除项 | 宏平均 rho | 相对完整模型变化 |
|---|---:|---:|
| hyper_burden | 0.414 | -0.121 |
| hypo_burden | 0.535 | 约0 |
| variation_load | 0.535 | 约0 |
| recovery_debt | 0.533 | -0.002 |
| anchor_level | 0.494 | -0.041 |

只有高糖负荷和夜间锚点带来明确排序贡献；低糖负荷、波动负荷和恢复债务没有形成稳定增量。

## 9. CCAS 定义敏感性

把软阈值斜率改为2/4/6、最大项权重改为0.50/0.60/0.75，共9种预设组合。使用各外层默认目标已选择的超参数重新拟合，宏平均 rho 范围为：

```text
0.5341 – 0.5402
```

因此总体结论不是由单个 sigmoid 斜率或最大项权重造成。所有组合中 Colas rho 仍只有0.137–0.162，跨队列瓶颈持续存在。

## 10. Hall 已揭盲探索结果

### 10.1 `CCAS-full`

使用完全不含 Hall 标签的 CGMacros+Colas 训练折预测，Hall 完整样本 n=41：

| 指标 | 结果 |
|---|---:|
| Spearman | **0.648** |
| 95% CI | 0.436–0.797 |
| R² | 0.0067 |
| MAE | 25.85 |
| 相对 `night_mean` rho 增量 | **+0.223** |
| 增量95% CI | 0.023–0.442 |

这是当前最有价值的信号：模型在 Hall 的连续完整临床靶标上首次略微取得正 R²，并且相对夜间均糖的排序增量区间大于0。但研究方向本身已受到上一轮 Hall 结果影响，因此仍属于探索性再分析，不能升级为独立确认。

SSPG 软映射尺度为15/25/35时，Spearman分别为0.641/0.648/0.644；只使用A1C/FPG/OGTT糖代谢部分时为0.692，方向稳定。

## 13. 结论与下一步

五维方向优于九维方向：有界形式解决了输出越界，宏平均排序显著优于夜间均糖和单一锚点，主队列24/48小时稳定性也全部达到门槛。Hall `CCAS-full` 和隐藏异常点估计进一步支持高糖暴露与夜间锚点可能捕获接近阈值的血糖异常。

但当前证据仍不能冻结公式。主要障碍不是“总分不够高”，而是：

1. Colas 的跨队列相关仍低；
2. Libre/Dexcom 存在约16分的绝对偏移；
3. 模型被高糖负荷主导；
4. 低糖、波动和恢复三维没有稳定增量；
5. 稳定性惩罚的选择本身不稳定；
6. 没有新的、尚未查看的临床队列可供最终确认。

继续在现有 Hall 上调权或选阈值会扩大验证偏差。下一次有价值的研究应优先检查 `hyper_burden` 的设备校准和跨治疗队列定义，或引入一个新的同时含A1C、FPG、OGTT/直接胰岛素抵抗测量的独立队列；在此之前保持 `index.html` 不变。
