# GlucoBench v8.3 实验报告：外部验证揭示方向性反转 + RQA 抽样标定 bugfix + 模型重定向至未治疗筛查人群

- **日期**: 2026-08-07
- **目标**: 对 v8.1/v8.2 已部署管线做**首次外部验证**（Hall/PLOS Biol 队列，含真实诊断标签与 OGTT/胰岛素金标准），并回答 v8.1 报告遗留的 DET 去饱和问题
- **结论摘要**: 外部验证**否定**了 v8.0/v8.1 的部署筛查模型：Colas 三特征 LR（lyap+entr+nightMean，OOF AUC 0.670）在未治疗的 Hall 队列上**方向性反转**（AUC 0.414 < 0.5，与 A1C/FBG/insulin 负相关）。根因：Colas 阳性为**已治疗** T2DM，药物压低波动使 lyap/entr/volume 的方向与未治疗人群相反；**夜间均糖是唯一跨队列方向稳定的特征**。v8.3 将筛查模型更换为 Hall 校准的夜间均糖单特征 LR（10x5 OOF AUC **0.727**，置换 p=0.010），并把全部 MRI 卡片阈值按 Hall（未治疗）分布重定向。同时修复一个**部署 RQA 抽样标定 bug**：长序列（n≈2950-3900 及部分更长区间）rr/det/entr 全部返回 0，Colas 队列（n≤1151）从未触发所以 v8.1 回归漏检。

## 1. 背景与目标

v8.0 建立了 Colas 校准筛查模型（Lyapunov + ENTR + 夜间均糖，OOF AUC 0.670），v8.1 优化性能并按 Colas 实测分布重校准全部 MRI 阈值，v8.2 重拟合 FINS（阴性）。两份报告共同列出的**最高优先级遗留问题**是外部验证：

1. **模型泛化性未知**：模型只在 Colas 单一队列（208 人，17 例**已治疗** T2DM）上校准与评估；Weinstock/Hall 的 HbA1c/FBG 代理标签验证从未执行。
2. **长序列 RQA 未经验证**：v8.1 引入 >4M 距离对时抽样标定 epsilon 的路径，微基准通过但从未在真实长序列上回归。
3. **DET 去饱和**：修复后 DET≈99% 压缩在 0.02 范围内，v8.1 §8.2 建议降低 RR 目标恢复动态范围——未实验。

本次实验回答三个问题：

1. 部署模型在独立队列（含真实诊断标签 + OGTT/胰岛素金标准）上是否成立？方向是否一致？
2. 长序列 RQA 抽样标定路径是否正确？
3. RR 目标降到 0.5% 能否恢复 DET/ENTR 动态范围与判别力？

## 3. 关键发现

### 3.1 部署 bug：RQA 抽样标定在长序列上返回全零（已修复）

Hall 队列首批跑批即发现 57 人中 38 人 `entr=0.000`、`det=0`、`rr=0`（如 1636-69-001：n=3627）。手工强制全量模式（截断至 2500 点）给出正常值 det=0.9938/entr=3.047——**抽样标定路径输出垃圾**。

根因（两处叠加）：

1. `epsIdx = floor(0.02 * sampleLen)` 用 **sampleLen（1M）** 计算百分位下标，但步进抽样实际只填了 `ptr ≈ totalPairs/stride` 个条目（如 n=3627：ptr=938,357）；未填充的 Float64Array 尾段为 **0**。
2. `quickselect` 在**含零填充的整个数组**上运行；0 是最小值排在最前，当 padding > epsIdx（即 totalPairs/stride < 980,000，n≈2950–3900 及 4800 附近等区间）时，k-th 最小元素就是 0 → `epsilon=0` → 无任何递归 → rr=det=entr=0。

修复：`epsIdx` 改用实际填充数 `ptr`，且 quickselect 作用于 `dists.subarray(0, ptr)`。全量模式 `ptr === sampleLen`，两处改动在语义上完全等价——**Colas 回归 208×11 字段逐位 0 差异**。Hall 修复后验证：1636-69-001 det=0.9941/entr=3.072（正常），1636-69-035 不变（原正确），1636-69-104（另一损坏区间）恢复 det=0.9752/entr=2.546。

教训（第三次同型）：**校准与验证必须覆盖部署实现的每条路径**；v8.1 的"抽样标定"只在合成微基准上验证过，Colas n≤1151 永远走全量路径，回归测试天然盲区。

### 3.2 外部验证：部署模型在目标人群上方向性反转（核心发现）

| 评估 | 结果 |
|---|---|
| 部署 LR（lyap+entr+nightMean）在 Hall 上，正常 vs 前期+糖尿病 | **AUC = 0.414**（<0.5，反转） |
| 正常 vs 仅糖尿病（n=5，方向性参考） | AUC = 0.342 |
| 风险 vs A1C / FBG / insulin（Spearman） | **−0.155 / −0.156 / −0.188**（负相关！） |
| 部署阈值 0.30 / 0.50 / 0.70 在 Hall 上 | Sens 1.00/Spec 0.00；0.684/0.158；0.105/0.842（0.30 把所有正常人都标成阳性） |

特征方向审计（组均值，非/pre/糖尿病）：

| 特征 | Colas（已治疗 T2DM 方向） | Hall（未治疗方向） | 结论 |
|---|---|---|---|
| lyapunov | T2DM **更高**（0.161 vs 0.120） | 糖尿病**更低**（0.156 vs 0.217） | **反转** |
| entr | T2DM **更低**（2.786 vs 2.964） | 糖尿病**更高**（2.978 vs 2.657） | **反转** |
| volume | T2DM 更低（1.62 vs 2.26） | 糖尿病**更高**（30.5 vs 4.9） | **反转** |
| det | T2DM 更低（0.993 vs 0.995） | 糖尿病**更高**（0.991 vs 0.984） | **反转** |
| avgRecovery | 无分离 | 糖尿病更低（0.131 vs 0.193） | 反向弱信号 |
| **nightMean** | T2DM 更高 | 糖尿病更高（6.06 vs 5.40） | **方向稳定** ✓ |

解读：Colas 的 17 例 T2DM 全部在用药（二甲双胍/胰岛素等），药物压制血糖波动 → 吸引子被压扁（volume 小、entr 低、det 高→低、lyap 高）；而筛查的目标人群是**未治疗的隐性异常**（如 Hall 的糖尿病前期/新诊断），其吸引子特征是波动增大（volume 大、entr 高、det 高、lyap 低）。v8.0/v8.1 的"校准"实际拟合的是**治疗伪影**而非疾病本身——这正是 v8.0 报告 §7 警告过的方向（"药物压低信号，方向可能与未治疗人群不同"），现在被外部数据证实。

### 3.3 夜间均糖：唯一跨队列稳定特征

| 模型（LR，10x5 OOF） | Hall OOF AUC | Hall→Colas | Colas→Hall |
|---|---|---|---|
| 部署三特征（entr+lyap+nightMean） | 0.738±0.013 | 0.402（反转） | 0.323（反转） |
| nightMean + volume | 0.752±0.010 | 0.590 | 0.521 |
| **nightMean 单特征** | **0.727±0.009** | **0.625** | **0.751** |
| all7 | 0.703±0.020 | — | — |

置换检验（200 次）：nightMean 单特征 OOF AUC=0.712–0.727，null 均值 0.482，null p95=0.640，**p=0.010**；nightMean+volume p=0.005。体积虽在 Hall 上略升 AUC（0.752 vs 0.727），但其方向在已治疗/未治疗人群间反转（3.2 表），跨队列迁移反而变差（Colas→Hall 0.751→0.521）——**部署选择单特征夜间均糖**：简单、方向稳定、生理可解释（黎明/基础血糖升高是早期异常的首要表现）。

临床参照上限（同队列单特征 AUC，正常 vs 前期+糖尿病）：A1C 0.900、FBG 0.929、OGTT-2h 0.781。CGM 夜间均糖 0.727 已接近 OGTT，但低于 A1C/FBG——符合"CGM 单模接近但低于生化金标准"的预期。

### 3.4 MRI 阈值在目标人群上系统性误报（已按 Hall 重定向）

v8.1 按 Colas（已治疗）校准的阈值在 Hall（未治疗）上命中率严重倒挂——注意 v8.1 时这些方向是"按实测校准"的，问题不在校准方法而在**校准人群**：

| 阈值（v8.1，Colas 定向） | Hall 正常命中 | Hall 糖尿病命中 | 问题 |
|---|---|---|---|
| det < 0.990（bad） | **95%** | 40% | 健康人被误报 |
| det < 0.994（warn） | 97% | 60% | 同上 |
| entr < 2.6（bad） | **39%** | 0% | 反转 |
| entr < 2.9（warn） | 89% | 40% | 反转 |
| lyap > 0.15（warn） | **92%** | 80% | 反转 |
| lyap > 0.20（bad） | 61% | 20% | 反转 |
| volume < 1.0（warn-lo） | 13% | 0% | 低体积=健康方向 |
| recovery > 0.145（warn-hi） | 高频命中 | — | 高恢复=健康方向 |

v8.3 按 Hall（未治疗筛查目标）分布重定向全部卡片：volume 只留高端 log>2/3（3%/14%/60% 递增）；Recovery 只留低端 <0.14/0.10（8%/29%/60%）；Lyapunov 改低端 <0.15/0.11（8%/36%/20%，n=5 糖尿病噪音大但组均值单调）；DET 改高端 >0.990/0.992（5%/36%/60%）；ENTR 改高端 >2.85/3.0（13%/36%/60%）；Dimension 改 Hall 分位双尾 1.80/1.81–2.01/2.02（原 1.38–1.70 区间对 Hall 全人群 100% 命中，因 Hall 范围 1.795–2.033）。

### 3.5 DET/ENTR 去饱和实验（阴性结论）

RR 目标 2%→0.5% 探针（同嵌入、同 epsilon 路径）：

| 指标 | 动态范围 sd（2%→0.5%） | AUC（2%→0.5%） |
|---|---|---|
| det | 0.0061 → 0.0156（2.5 倍） | 0.767 → 0.767（不变） |
| entr | 0.238 → 0.257 | 0.774 → 0.691（略降） |

结论：降 RR 确实恢复 DET 动态范围，但**判别力不升反平/降**——去饱和不解决信息问题（DET/ENTR 本身在 Hall 上是反方向信号，3.2 表）。维持 RR=2% 部署不变。

### 3.6 FINS 在 Hall（其训练集同源队列）上的一致性

部署 FINS 卡片在 57 人上的预测 vs 实际胰岛素：MAE 3.76 uIU/mL、Pearson r=0.177（n=57，含其训练集本身，属样本内）——与"均值回推器"定位一致（R²≈0.01，v8.2 结论），卡片维持实验性标签。

3. **Hall 复算**：修复后 57 人全部取得有效 RQA 指标（此前 38 人全零），风险分布正常。

## 6. 局限

- **Hall n=57（19 阳性，其中糖尿病仅 5 例）**：新模型的 AUC 与阈值有宽置信区间；糖尿病组均值方向单调但小样本噪音大。夜间均糖单特征的选择同时受"跨队列稳定"与"Hall 表现"双重证据支持，但 0.727 与 0.752（+volume）的差异不显著，选单特征是稳健性决策而非性能决策。
- **Hall 与 FINS 训练集同源**（data1/）：FINS 卡片在 Hall 上属样本内评估，仅作一致性检查。
- **仍为单数据集校准**：新模型校准于 Hall，Colas 已治疗人群不再适用（已明确标注）；Weinstock（T1DM 队列，全部阳性）只能做"已知病应高分"的合理性检查，无法做判别验证。
- **MRI 卡片命中率校准于 n=57**：阈值是参考性标记，主评级由 0.727 AUC 的 LR 驱动。
- **DET/ENTR 在 Hall 上的"反向信号"方向**：与 Colas 相反但方向单调（3.2 表），未做置换检验验证这些单特征方向（n=57 功效不足）。

## 7. 进一步改进方向

1. **Weinstock 干预敏感性检查**（v8.0 §8.1-1 未执行）：Weinstock 为 T1DM 干预前后记录，可验证"风险随干预下降"的响应性——这是新模型在"已知病"上唯一可测的性质。
2. **收集未治疗 OGTT 标签队列扩样**：Hall 证明未治疗人群信号方向与已治疗相反；需要 >100 例未治疗（最好 OGTT 标签）队列把 0.727 的置信区间收窄，并重新评估多特征模型。
3. **夜间均糖窗口细分**：Hall 数据记录 6-7 天，可评估 0-3h vs 3-6h、连续多夜均值的稳定性（当前单文件可能跨 1-2 夜）。
4. **CI 固化回归**（两次遗留）：把 `js_cohort.mjs` 断言 + 本次新增的**长序列抽样路径回归**（构造 n≈3500 合成序列断言 det/entr 非零）纳入 CI——本次 bug 恰是"短队列回归测不到长序列路径"的教训。
5. **去饱和关闭**：3.5 证明 RR=0.5% 无判别收益，此方向不再追。
6. **治疗状态作为显式输入**：若工具面向已治疗用户，Colas 定向模型仍有其适用域；可考虑 UI 增加"是否用药"开关切换两套阈值（当前只部署未治疗定向）。
