# GlucoBench 全参考指标实验：治疗状态分流的相空间共识机制

- **日期**：2026-08-07
- **用户初始问题**：综合 Lyapunov、DET、ENTR、相空间体积及其他参考指标，设计比夜间均糖更优的筛查机制
- **研究方向**：治疗状态分流 + 动力学共识 + 结构共识 + 证据一致性门控
- **部署结论**：**不更新 `index.html`**。未治疗人群的点估计改善明显但不确定性仍大；已治疗人群未达到增益、显著性、校准和操作点门槛
- **最重要发现**：Lyapunov/DET/ENTR 的压缩动力学共识比“强制使用所有指标”更有价值；治疗方向用错时 AUC 会降到 0.42/0.34，治疗状态分流是安全前提而非可选优化

---

## 1. 背景

当前 v8.3 的主风险只使用 0:00–6:00 夜间平均血糖：

```text
P = sigmoid(1.064314 × nightMean − 6.746364)
```

Lyapunov、DET、ENTR、体积、恢复速度、维度、形状比和引力核偏移仅作为参考卡片。既往实验已经发现，部分相空间指标在两类人群中方向相反：

- Hall：未治疗的糖尿病前期/糖尿病筛查目标；
- Colas：阳性者为已治疗 T2DM，药物改变了波动结构。

因此本轮没有建立一个跨所有人的单一“全指标回归”，而是预注册治疗状态分流：已知未治疗、已知使用降糖药、治疗状态未知分别走不同路径。

## 2. 数据与现行 JS 指标重算

| 队列 | 人数 | 阳性 | 人群定义 | 主要标签 |
|---|---:|---:|---|---|
| Hall | 57 | 19 | 未治疗 | `diagnosis >= 1` |
| Colas | 208 | 17 | 阳性为已治疗 T2DM | `T2DM` |

原始数据直接从 `raw_data.zip` 只读导出。`extract_phase_screening_metrics.mjs` 没有复制 Python 算法，而是在 Node VM 中直接执行 `index.html` 的当前 v8.3 内联脚本，并调用生产函数完成：

```text
单位换算 → JS 原生重采样 → ACF/τ → SYC 嵌入维度
→ Takens 嵌入 → Volume/Shape/Recovery/Dimension/Lyapunov

```

质量检查：

- Hall 57/57、Colas 208/208 均取得全部指标；
- 265 人中 DET、ENTR、RR 无零值、无缺失；
- Hall 长序列覆盖曾发生抽样 epsilon 错误的 3,000–4,000 点路径；
- RR 保持在目标 2% 附近。

## 3. 预注册白盒机制

### 3.1 训练折内健康参考

每个外层训练折仅使用该折的阴性受试者计算各指标的健康中位数与稳健尺度：

```text
robust_z = (指标 − 健康中位数) / (1.4826 × MAD)
robust_z 截断在 −3～+3
```

MAD 为零时依次使用 IQR/1.349、标准差和安全常数。测试折从不参与参考值估计。

### 3.2 治疗状态方向

| 分组 | 未治疗异常方向 | 已治疗异常方向 |
|---|---|---|
| 动力学 | Lyapunov 低、DET 高、ENTR 高 | Lyapunov 高、DET 低、ENTR 低 |
| 结构定向 | Volume 高、Recovery 低、Core displacement 高 | Volume 低、Recovery 高、Core displacement 低 |
| 结构双尾 | Dimension 和 ShapeRatio 偏离健康参考超过 1 个稳健尺度 | 同左 |

每项证据均转为 `0～3` 的非负异常分。健康方向不能给其他异常证据“抵消扣分”。

### 3.3 两个共识分

```text
DynamicScore = median(
  Lyapunov方向分, DET方向分, ENTR方向分
)

StructureScore = median(
  log(Volume)方向分, Recovery方向分, Core方向分,
  Dimension双尾分, ShapeRatio双尾分
)
```

中位数要求同一组至少半数指标支持异常，避免单个阈值或传感器噪声主导风险。

### 3.4 证据门控

相空间证据只有同时满足以下条件才可调整风险：

```text
8 项参考指标中至少 3 项 evidence > 0.5
且 0.015 <= RR <= 0.025
```

否则 `gatedDynamic=gatedStructure=0`，模型退化为夜间均糖路径。

最终预注册候选：

```text
logit(P) = β0
         + β1 × nightMean
         + β2 × gatedDynamic
         + β3 × gatedStructure

β1, β2, β3 >= 0
```

非负约束通过枚举所有活跃系数面并选择最小惩罚损失的凸解实现；不存在把预设异常方向重新拟合成保护方向的可能。

## 4. 验证协议与部署门槛

- 10×5 受试者级重复分层外层交叉验证；
- 健康参考、共识转换、标准化和逻辑回归均仅在训练折拟合；
- 内层 3×5 OOF 选择满足灵敏度 ≥0.75 时特异度最高的筛查阈值；
- 2,000 次阳性/阴性分层配对 bootstrap 估计 ΔAUC；
- 250 次标签置换；在 raw-all、未门控共识和门控共识三种新机制的最大 AUC 上做 max-statistic 校正；
- 指标：ROC AUC、PR-AUC、Brier、灵敏度、特异度、平衡准确率；
- Hall 的空腹胰岛素与 SSPG 仅作机制性次要终点。

每个治疗层必须全部满足：

1. 相对夜间均糖 `ΔAUC >= 0.03`；
2. bootstrap 95% CI 下限 `>0`；
3. maxT 置换检验 `p<=0.05`；
4. Brier 不差于夜间均糖；
5. 灵敏度目标下的嵌套特异度不降低超过 0.02。

只有 Hall 与 Colas 两个已知治疗层都通过，才允许部署双模型。治疗状态未知必须原样回退 v8.3。

## 5. Hall 未治疗人群结果

| 模型 | OOF AUC | PR-AUC | Brier |
|---|---:|---:|---:|
| 夜间均糖 | 0.730 | 0.527 | 0.199 |
| 原始全部指标直接回归 | 0.730 | 0.597 | 0.194 |
| 夜间均糖 + 动力学共识 | **0.773** | 0.691 | **0.173** |
| 夜间均糖 + 结构共识 | 0.749 | 0.563 | 0.192 |
| 未门控完整共识 | 0.770 | **0.693** | 0.177 |
| **预注册门控完整共识** | **0.769** | 0.692 | 0.177 |
| 仅相空间共识 | 0.713 | 0.640 | 0.177 |

预注册门控机制相对基线：

- `ΔAUC = +0.039`；
- 配对 bootstrap 95% CI：`−0.078～+0.147`；
- ΔAUC>0 的 bootstrap 比例：73.3%；
- maxT 校正置换 `p=0.004`；
- 相空间证据门命中 52.6% 受试者。

该模型有真实判别信号，但无法证明增益稳定存在。置换 p 值回答“是否优于随机零假设”，bootstrap 差值区间回答“是否优于已有模型”；两者含义不同。

### 5.1 筛查操作点

| 模型 | 内层阈值中位数 | 外层灵敏度 | 外层特异度 | 平衡准确率 |
|---|---:|---:|---:|---:|
| 夜间均糖 | 0.302 | 0.762 | 0.650 | 0.706 |
| 门控完整共识 | 0.233 | 0.733 | 0.591 | 0.662 |

虽然 AUC 点估计提高，实际筛查阈值下灵敏度和特异度同时下降，未通过操作点门槛。

  + 0.985441 × gatedDynamic

## 7. 治疗状态安全性

| 检查 | AUC |
|---|---:|
| 未治疗模型错误用于 Colas | **0.420** |
| 已治疗模型错误用于 Hall | **0.337** |
| 治疗未知回退 v8.3：Hall | 0.751（固定公式同队列表观值） |
| 治疗未知回退 v8.3：Colas | 0.625（固定公式同队列表观值） |

错误方向会让风险排序低于随机。由此得到的工程结论非常明确：在没有可靠治疗状态输入时，Lyapunov/DET/ENTR/Volume 等相空间指标**不能改变主风险**。

本轮安全退化实现为数学上的恒等回退：

```text
治疗状态未知 → phase adjustment = 0
→ P = sigmoid(1.064314 × nightMean − 6.746364)
```

与当前 `currentRisk` 最大绝对差为 0。

## 8. 空腹胰岛素和 SSPG

Hall 全量探索性相关：

| 特征 | 空腹胰岛素 ρ | SSPG ρ |
|---|---:|---:|
| nightMean | 0.344 | 0.443 |
| DynamicScore | 0.358 | 0.154 |
| StructureScore | −0.024 | −0.026 |
| gatedDynamic | 0.327 | 0.150 |
| gatedStructure | 0.031 | −0.009 |

三特征共识模型对连续终点的 LOO 结果：

| 终点 | LOO R² | MAE |
|---|---:|---:|
| 空腹胰岛素 | −0.001 | 3.33 uIU/mL |
| SSPG | −0.097 | 59.5 |

动力学共识与空腹胰岛素存在相关趋势，但加入全部参考指标仍不能进行个体胰岛素或 SSPG 数值预测。结构共识没有机制性支持。

## 9. 消融结论

1. **直接使用所有原始指标并不好**：Hall AUC 与夜间均糖相同，Colas 反而降至 0.545。
2. **有效增量主要来自 Lyapunov/DET/ENTR 动力学共识**：Hall 0.773、Colas 0.643，均为各层最佳点估计。
3. **结构指标更适合解释或异常画像**：加入结构共识没有提高最佳 AUC，且在胰岛素/SSPG 上无相关。
4. **证据门控没有带来额外性能**：门控与未门控 Hall 0.769/0.770，Colas 0.619/0.623；其主要价值是安全解释，而非性能提升。
5. **治疗分流不可省略**：错误模型产生明显方向性反转。

## 11. 最终 HTML/JS 决策

`index.html` 保持 v8.3，不增加治疗状态输入，不把实验性共识公式写入主风险。最终部署逻辑仍为：

```javascript
const z = 1.064314 * nightMean - 6.746364;
const screenRisk = 1 / (1 + Math.exp(-z));
```

Lyapunov、DET、ENTR、Volume、Recovery、Dimension、ShapeRatio 和 Core displacement 继续作为参考卡片，而不是主概率的隐式组成部分。

这不是“综合指标没有价值”，而是更具体的结论：**动力学共识值得在新数据上预注册复验；目前没有足够证据把所有参考指标上线。**

## 13. 局限

1. Hall 仅 57 人/19 阳性，Colas 仅 17 个已治疗阳性，AUC 差值区间宽。
2. 两个治疗层分别只有一个队列，没有独立的同治疗状态外部验证。
3. Colas 阴性者与阳性者除治疗状态外还可能存在年龄、疾病时长等队列差异。
4. 健康参考 MAD、证据阈值 0.5 和“至少 3 项一致”是预注册工程定义，仍需外部验证。
5. Dimension、ShapeRatio 等双尾指标缺乏疾病方向，其主要作用是异常画像而非病因判别。
6. 固定钟表夜间窗口无法识别睡眠、进餐、轮班和时区变化。
7. maxT 置换证明模型族有信号，但不能替代配对增益区间和独立外部验证。

## 14. 后续建议

1. **下一轮只预注册“夜间均糖 + 动力学共识”**，不再强制加入结构指标；这是本轮两个治疗层中一致的最佳点估计。
2. **收集独立的治疗状态明确队列**：至少一个未治疗 OGTT/SSPG 队列和一个已治疗 T2DM 队列。
3. **治疗状态必须来自用户明确输入或结构化数据**；未知时永久保留夜间均糖安全回退。
4. **结构指标保留为解释卡片**，在获得独立增量证据前不进入概率。
5. **扩大阳性样本**：当前 bootstrap 区间说明现有样本无法分辨约 0.03–0.04 的实际增益。
6. **冻结本轮健康参考和方向表**；在新数据上一次性验证，避免继续用 Hall/Colas 调参。
