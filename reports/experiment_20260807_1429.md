# GlucoBench 结构共识应用研究：未来脆弱性、结构表型与临床关联

- **日期**：2026-08-07
- **用户问题**：尝试探究结构共识的更多应用可能性
- **冻结方向**：未来波动预测、结构表型、临床关联和记录长度稳定性
- **主要结论**：总体结构共识不能改善未来脆弱性预测，也不具备跨记录长度稳定性；不加入前端
- **保留假设**：未治疗人群的“扩张型结构”与 OGTT 2小时血糖存在值得独立复验的探索性关联
- **部署决定**：`index.html` 不修改，继续保留现行 v8.4 动力学共识筛查

## 1. 为什么改变结构指标的应用目标

此前结构共识直接加入异常胰岛素筛查时没有稳定增益，对空腹胰岛素和 SSPG 的机制性预测也很弱。本轮不再把结构指标强制解释为“异常胰岛素概率”，而是测试三个更符合其物理含义的用途：

1. 前几天吸引子结构是否能预测随后几天的血糖脆弱性；
2. 是否可形成扩张、收缩和几何异常三种可解释表型；
3. 是否与严重低血糖史、并发症、OGTT 或代谢实验室指标有关。

## 2. 数据与时间窗

### 2.1 主要队列：Weinstock

- 200 名 T1D 受试者，原始记录中位约 13.9 天；
- 有泵/注射方式、胰岛素总量、严重低血糖史及多项并发症标签；
- 178 人满足前3天预测窗和随后第4–5天结局窗的覆盖要求；
- 19 人因未来窗不足排除，另有少量受试者因早期覆盖不足排除；排除不使用结局值。

### 2.2 小样本复核：Hall

- 57 名未治疗受试者；
- 有 A1C、FBG、OGTT 2小时血糖、空腹胰岛素、SSPG 和既有 CGM 波动指标；
- 53 人满足前3天和后2天时间窗要求；
- 原始数据中的 `-1` 按数据字典惯例作为缺失，不进入临床相关分析。

所有数据均从 `raw_data.zip` 只读读取，没有提取或覆盖原始医疗数据。血糖在衍生输出中转换为 mmol/L。

## 3. 同源结构指标

每个1/2/3天早期窗口均直接执行 `index.html` 当前 v8.4 数值函数：

```text
重采样 → ACF/推荐Tau → SYC嵌入维度 → Takens嵌入
→ Volume / Recovery / Core displacement / Dimension / ShapeRatio
```

本研究不使用 Lyapunov、DET 或 ENTR，因此跳过 RQA；结构指标计算本身没有改写或近似。3天主窗口在 Weinstock 178/178、Hall 53/53 中均完整可计算。

## 4. 冻结结构共识

训练折中分别对以下五项计算中位数和稳健尺度：

```text
log(Volume), Recovery, Core displacement, Dimension, log(ShapeRatio)
```

每项证据为：

```text
evidence_j = clip(|robust_z_j| − 1, 0, 3)

StructureScore = median(evidence_1 ... evidence_5)
```

结构分数只有在至少三项指标同时偏离训练折典型值超过约1个稳健尺度时才明显升高。该定义不依赖治疗方向。

另外预先定义三个解释轴：

- **扩张轴**：高 Volume、慢 Recovery、高 Core displacement 的中位证据；
- **收缩轴**：低 Volume、快 Recovery、低 Core displacement 的中位证据；
- **几何轴**：Dimension 与 ShapeRatio 双尾偏离。

## 5. 未来脆弱性目标

预测窗为每名受试者最初3个完整 elapsed days；结局窗为随后第4–5天。未来脆弱性定义为：

```text
FutureFragility = 0.5 × percentile(future CV)
                 + 0.5 × percentile(future fraction outside 3.9–10 mmol/L)
```

最高四分位为内部“高未来脆弱性”标签。该标签是研究表型，不是临床诊断或指南阈值。

传统 CGM 比较模型使用早期 `CV + 范围外比例`；冻结候选再加入 `StructureScore`，所有系数非负。验证采用：

- 20×5 受试者级重复分层交叉验证；
- 训练折内结构参考、标准化和模型拟合；
- 5,000 次分层配对 Bootstrap；
- 1,000 次固定候选标签置换；
- 内层 3×5 OOF 选择灵敏度目标阈值；
- 评价 ROC AUC、PR-AUC、Brier、校准、灵敏度和特异度。

## 6. Weinstock 主要结果

| 模型 | OOF AUC | PR-AUC | Brier | 与连续未来脆弱性 ρ |
|---|---:|---:|---:|---:|
| 早期传统 CGM | **0.699** | **0.446** | **0.1729** | **0.327** |
| 仅总体结构共识 | 0.481 | 0.241 | 0.1889 | 0.049 |
| 传统 CGM + 总体结构共识 | **0.699** | **0.446** | **0.1729** | **0.327** |
| 传统 CGM + 扩张轴 | 0.698 | 0.446 | 0.1736 | 0.324 |
| 传统 CGM + 收缩轴 | 0.698 | 0.446 | 0.1730 | 0.320 |
| 传统 CGM + 几何轴 | 0.698 | 0.446 | 0.1729 | 0.326 |

冻结候选的结构系数在 100/100 个外层拟合中均为 0，因此候选概率与传统 CGM 概率完全相同：

- `ΔAUC=0.000`；
- Bootstrap 95% CI `0.000～0.000`；
- 固定候选择换 `p=0.564`；
- Brier 无改善。

### 6.1 筛查操作点

| 模型 | 阈值中位数 | 外层灵敏度 | 外层特异度 | 平衡准确率 |
|---|---:|---:|---:|---:|
| 传统 CGM | 0.216 | 0.729 | 0.514 | 0.621 |
| 传统 CGM + 结构共识 | 0.213 | 0.740 | 0.517 | 0.628 |

小幅阈值差来自嵌套折的拟合波动，不代表主模型获得结构增益。

## 7. Hall 时间复核

| 模型 | OOF AUC | PR-AUC | Brier | 与连续未来脆弱性 ρ |
|---|---:|---:|---:|---:|
| 早期传统 CGM | **0.850** | 0.550 | 0.1641 | 0.629 |
| 仅总体结构共识 | 0.346 | 0.240 | 0.1990 | −0.027 |
| 传统 CGM + 总体结构共识 | 0.841 | 0.534 | 0.1699 | 0.633 |
| 传统 CGM + 扩张轴 | 0.848 | 0.546 | 0.1646 | 0.628 |
| 传统 CGM + 收缩轴 | 0.850 | 0.550 | 0.1641 | 0.629 |
| 传统 CGM + 几何轴 | 0.842 | **0.589** | **0.1633** | 0.615 |

冻结候选相对传统模型：

- `ΔAUC=−0.009`；
- Bootstrap 95% CI `−0.029～+0.004`；

- 结构系数在80%的外层拟合中为正，但没有转化为判别或Brier改善。

Hall 没有复现正增益。

## 8. 记录长度稳定性

稳定性同时使用两种方法：

1. 每种记录长度建立自己的留一受试者参考，消除长度尺度差异；
2. 固定使用3天参考套用1/2天，作为诊断性敏感分析。

主报告采用时长归一化结果：

| 队列 | 1天 vs 3天 ρ | 2天 vs 3天 ρ | 2天 vs 3天 MAE | 全窗口可计算率 |
|---|---:|---:|---:|---:|
| Weinstock | 0.172 | 0.474 | 0.089 | 97.1% |
| Hall | 0.166 | 0.408 | 0.087 | 96.2% |

即使对记录长度分别校准，相关性仍远低于预设 `ρ>=0.8`。结构分数还非常稀疏：3天时 Weinstock 75.3%、Hall 72.5%的受试者得分为0。它不适合作为1–3天之间可直接比较的连续纵向指标。

这项失败反而支持一个数据质量用途：**结构表型必须标记具体记录长度，不能把1天和3天结果当作同一标尺；少于3天时不应显示稳定结构结论。**

## 10. 临床关联应用

### 10.1 Weinstock T1D

总体结构共识与主要标签几乎无关：

- 严重低血糖史 `ρ=−0.014`；
- 胰岛素总量 `ρ=−0.008`；
- 并发症数量 `ρ=0.143`；
- 任一并发症描述性 AUC 0.546；
- 泵 vs 注射描述性 AUC 0.492。

三个结构轴也没有形成一致、更强的信号。结构共识不适合识别泵治疗、胰岛素需求、严重低血糖史或并发症。

### 10.2 Hall 未治疗人群

在预设的4个结构特征 × 5个临床终点共20项检查中，只有一个关联通过2,000次 maxT 校正：

```text
扩张轴 vs OGTT 2小时血糖:
Spearman ρ = 0.422
maxT校正 p = 0.044
```

影响分析：

- 有效样本 51 人，其中扩张轴>0仅8人；
- 普通 Bootstrap 95% CI：`0.155～0.623`；
- 逐人剔除后 ρ 范围 `0.368～0.475`，中位数0.424；
- 扩张活跃者 OGTT 中位数 170.5 mg/dL，非活跃者113.0 mg/dL。

该结果不由单个受试者主导，但它是在同一 Hall 数据上观察、筛选并追加影响分析，属于**后选择探索性发现**，不是确认性证据。其合理应用不是立即形成概率，而是作为下一个未治疗 OGTT 队列的预注册假设：

```text
高相空间体积 + 慢恢复 + 高日夜核心偏移
可能代表葡萄糖负荷后的结构性扩张表型
```

## 11. 应用可能性结论

| 潜在应用 | 结论 |
|---|---|
| 预测未来2天高波动/范围外暴露 | 否；对传统CGM无增益 |
| 单独作为未来脆弱性筛查 | 否；AUC低于随机附近 |
| 严重低血糖史或并发症识别 | 否；关联弱 |
| 泵/注射方式或胰岛素需求分型 | 否 |
| 1–3天纵向连续追踪 | 否；排序稳定性不足 |
| 数据质量/记录长度门控 | 有限可用；至少要求3天且标明时长 |
| 未治疗扩张型结构解释OGTT耐量 | **值得独立预注册复验**，当前不可部署 |

## 13. HTML/JS 决定

本轮不修改 `index.html`，不增加结构韧性概率或结构共识风险卡。现行 v8.4 继续使用夜间均糖 + Lyapunov/DET/ENTR 动力学共识；治疗未知时仍回退：

```javascript
const z = 1.064314 * nightMean - 6.746364;
const screenRisk = 1 / (1 + Math.exp(-z));
```

Volume、Recovery、Core displacement、Dimension 和 ShapeRatio 继续作为解释卡片。扩张型结构–OGTT 关联仅记录在报告中，不写入概率。

## 15. 局限与下一步

1. 未来脆弱性是内部排名复合，不是临床结局。
2. Hall 只有53个时间验证样本；扩张轴仅8个活跃者。
3. Weinstock全为T1D，Hall主要为未治疗正常/糖尿病前期，队列机制不同。
4. 结构分数采用五项中位数，造成约四分之三受试者得分为0；它可能过度保守。
5. 下一轮若继续，建议只预注册“扩张轴 vs 连续OGTT 2小时血糖”，使用至少3天CGM，在新的未治疗队列一次性验证；不再从总体结构共识中继续挑选权重。
6. Dubosson的进餐/胰岛素/活动数据仅9人，可作为事件对齐机制案例，但不足以承担确认性统计验证。
